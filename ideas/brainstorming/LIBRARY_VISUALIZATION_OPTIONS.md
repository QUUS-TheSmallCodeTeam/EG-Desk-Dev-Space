# Library (서재) Visualization Options

**작성일**: 2026-04-09
**상태**: Map Table 선택 확정. 대안 옵션 문서화 (교체 대비)
**용도**: design-agent가 화면 프롬프트로 직접 사용

---

## 선택된 옵션: Map Table / Blueprint

### 왜 선택했는가

1. **Mission Impossible 시점과 완벽 매칭** — 위에서 내려다보는 작전 지도. 프로젝트 정체성의 핵심 은유와 직결
2. **Ontology 연결** — 레퍼런스 간 관계(의존성, 참조, 카테고리)를 노드+엣지 그래프로 시각화할 수 있는 유일한 옵션
3. **3-State 자연스러움** — 접힌 지도 → 펼쳐진 작전 지도 → 전체 지형도
4. **꺼내기 행위 직관적** — 지도 위의 점을 끌어 책상 위에 놓기
5. **스케일 우수** — 레퍼런스 수가 늘어도 줌/팬으로 대응 (캔버스 안의 미니 캔버스)

### 은유

책상 위에 펼쳐진 작전 지도 + 건축 도면. 레퍼런스들이 지도 위의 "거점"처럼 배치됨. 거점 사이의 선이 관계를 나타냄.

### 3-State 상세

**Covered (접힌 지도)**
- 크기: 약 80x60px 카드
- 외형: 접힌 양피지/청사진 색상 (따뜻한 크림색 or 청사진 파랑). 접힌 모서리 보임
- 표면: "Library" 라벨 + 등록된 레퍼런스 수 배지 (예: "23")
- 질감: 종이 접힌 자국, 약간 낡은 느낌

**Spread (작전 지도 펼침)**
- 크기: 약 400x300px (조절 가능)
- 외형: 지도가 펼쳐지는 애니메이션 — 네 모서리가 바깥으로 접혀 열림
- 내용물:
  - 레퍼런스가 원형 노드로 배치 (아이콘 + 이름 라벨)
  - 노드 색상 = 태그 카테고리 (framework=파랑, tool=초록, docs=노랑 등)
  - 노드 사이 선 = 관계 (실선=의존, 점선=참조, 굵기=강도)
  - 상단에 검색/필터 바 (태그 토글 칩)
  - 현재 프로젝트 선반에 꽂힌 항목은 노드 테두리가 밝은 흰색 링 (활성 표시)
- 인터랙션: 노드 hover → 툴팁 (설명, URL, 태그). 노드 드래그 가능

**Full (전체 지형도)**
- 크기: 전체 viewport
- 외형: 전체 레지스트리를 줌/팬 가능한 그래프 뷰로 확대
- 추가 기능: 카테고리별 영역 분리 (섬/대륙처럼), 최근 추가 항목 글로우, 전체 텍스트 검색

### 꺼내기 행동 (Library → Shelf)

1. Spread 상태에서 노드를 지도 밖으로 드래그
2. 노드가 지도 경계를 넘는 순간 → 노드가 "떨어져 나오는" 애니메이션 (잉크 자국이 지도에 남음)
3. 책상 위에 놓으면 → 해당 레퍼런스가 선반에 clone됨. 책상 위에 레퍼런스 카드 객체 생성
4. 지도의 원본 노드는 유지됨 (테두리에 흰색 활성 링 추가)

### 되돌려놓기 (Shelf → Library)

1. 책상 위 레퍼런스 카드를 지도 위로 드래그
2. 지도 영역에 진입하면 → 흡입 효과 (카드가 노드로 축소)
3. 놓으면 → 선반에서 remove. 노드 활성 링 제거

### 장점
- MI 시점 + Ontology + 스케일 모두 충족
- 레퍼런스 관계를 시각적으로 탐색 가능
- 프로젝트 비전 (AI Agent Scaffold + Ontology)과 깊이 연결

### 단점
- 구현 복잡도 높음 (그래프 레이아웃 알고리즘 필요)
- 레퍼런스 수가 매우 적을 때 (3~5개) 허전할 수 있음
- 자동 배치 vs 수동 배치 결정 필요

## 대안 옵션 1: Reference Lamp (참고 등)

**순위**: 2위
**출처**: Codex CLI

### 은유

책상 위 스탠드 램프. 스위치를 켜면 빛의 원(pool of light) 안에 레퍼런스 타일이 투영됨. 빛 밖으로 꺼내면 실체화.

### 3-State 상세

**Covered (꺼진 램프)**
- 크기: 약 40x40px
- 외형: 작은 스탠드 램프 아이콘. 꺼진 상태. 램프 갓에 "Library" 각인
- 미세 효과: 전원 꺼진 램프의 어두운 실루엣

**Spread (켜진 램프 → 빛의 원)**
- 크기: 램프 중심에서 반경 약 200px 원형
- 외형: 램프를 클릭하면 "켜지는" 애니메이션 → 따뜻한 원형 빛이 책상 위에 투영
- 빛 안: 레퍼런스 타일이 반투명하게 떠 있음 (홀로그램 느낌). 태그별 색상
- 빛 밖: 일반 책상 표면 (레퍼런스 보이지 않음)
- 인터랙션: 빛의 원 안에서 스크롤/필터 가능. 빛 경계에서 fade out

**Full (최대 밝기)**
- 빛의 원이 전체 viewport로 확대. 모든 레퍼런스 표시 + 검색

### 꺼내기 행동

1. 빛 안의 타일을 빛 밖(일반 책상)으로 드래그
2. 타일이 빛 경계를 넘는 순간 → 반투명에서 불투명으로 "실체화" 애니메이션 (홀로그램 → 실물)
3. 책상 위에 실체 카드로 정착 → 선반에 clone

### 장점
- 가장 독창적. 앰비언트 AI 비전("보이지 않지만 항상 있는")과 강하게 공명
- Focus/Peripheral zone 개념과 자연스럽게 통합 (빛 = 탐색 focus)
- 작은 footprint (꺼두면 램프 하나)

### 단점
- "서재"라는 인지 즉각성 약함 (학습 곡선)
- 레퍼런스 간 관계 시각화 불가 (Map Table 대비 약점)

## 대안 옵션 2: Specimen Cabinet (표본함)

**순위**: 3위
**출처**: PM (Pinboard) + Codex (Specimen Cabinet) 통합

### 은유

책상에 낮게 매입된 유리 뚜껑 표본함. 위에서 투명 유리를 통해 내려다보면 핀으로 고정된 레퍼런스 카드가 보임.

### 3-State 상세

**Covered (닫힌 캐비닛)**
- 크기: 약 100x70px
- 외형: 유리 뚜껑에 황동 라벨. 유리를 통해 내부 카드 일부가 흐릿하게 비침
- 질감: 유리 반사광, 황동 프레임

**Spread (뚜껑 열림)**
- 크기: 약 350x250px
- 외형: 유리 뚜껑이 위로 슬라이드 (또는 한쪽으로 밀림) 애니메이션
- 내용물: 벨벳 배경 위에 핀으로 고정된 카드들. 카드에 이름 + 태그 색상 핀
  - 핀 색상 = 카테고리
  - 카드 배치 = 카테고리별 영역 구분
  - 선반에 활성화된 항목은 핀이 빛남 (밝은 핀)
- 인터랙션: 카드 hover → 확대 + 설명 툴팁

**Full (전체 전시)**
- 트레이가 위로 올라오며 팬 아웃. 전체 카탈로그 + 검색/필터

### 꺼내기 행동

1. 카드의 핀을 "뽑는" 제스처 (길게 누르기 → 핀 뽑힘 애니메이션)
2. 핀 빠진 카드를 캐비닛 밖으로 드래그
3. 캐비닛 안에는 핀 자국만 남음 (원본은 레지스트리에 유지 — 다음에 열면 카드 다시 있음)

### 장점
- MI 시점 최적 (위에서 유리를 통해 내려다봄)
- 프리미엄/큐레이션 느낌
- 구현 비교적 단순

### 단점
- 레퍼런스 간 관계 시각화 약함
- 대량 시 (50+) 혼잡할 수 있음

## 대안 옵션 3: Conveyor Hatch (컨베이어 해치)

**순위**: 4위
**출처**: Codex CLI

### 은유

책상 표면의 작은 투입구/해치. 열면 아래에서 컨베이어 벨트가 레퍼런스 카드를 실어옴.

### 3-State 상세

**Covered (닫힌 해치)**
- 크기: 약 60x40px
- 외형: 금속 해치 뚜껑. 큐 라이트 (대기 중인 항목 있으면 초록 점등)
- 라벨: "Library" 각인

**Spread (해치 열림 → 벨트 가동)**
- 크기: 약 400x80px (가로로 긴 벨트)
- 외형: 해치가 양옆으로 열리며 벨트 노출. 카드들이 천천히 좌→우로 이동
- 카드: 각 레퍼런스의 미니 카드 (아이콘 + 이름). 태그별 카드 색상
- 상단: 카테고리 필터 탭. 선택하면 해당 카드만 벨트에 올라옴
- 인터랙션: 벨트 스크롤 속도 조절 가능. 카드 hover → 정지 + 확대 프리뷰

**Full (전체 정렬 벨트)**
- 벨트가 다중 레인으로 확장. 카테고리별 레인. 전체 검색

### 꺼내기 행동

1. 벨트 위의 카드를 위로 "집어올려" 책상 위에 놓기
2. 벨트에서 카드가 빠지는 애니메이션 (빈 자리가 생기고 뒤 카드가 밀려옴)
3. 되돌리기: 카드를 해치 위에 놓으면 벨트로 빨려들어감

### 장점
- "글로벌 → 로컬" 전달이 가장 직관적
- AI 추천 레퍼런스를 벨트에 자연스럽게 배치 가능
- 동적/생동감 있는 UI

### 단점
- 동적 요소가 많아 산업적/기계적 느낌 위험
- 지속적 애니메이션이 주의를 분산시킬 수 있음
- MI 시점에서 "벨트"의 측면 움직임이 약간 부자연스러울 수 있음

## 대안 옵션 4: Rolodex (회전식 명함함)

**순위**: 5위
**출처**: PM + Gemini + Codex (3소스 수렴)

### 은유

책상 위의 회전식 카드 인덱스. 색인 탭이 달린 카드를 회전하며 브라우징.

### 3-State 상세

**Covered (닫힌 Rolodex)**
- 크기: 약 50x50px
- 외형: 작은 스핀들 실루엣. 카드 수 배지. 색상 탭 몇 개 삐져나옴

**Spread (펼쳐진 Rolodex)**
- 크기: 약 300x250px
- 외형: 카드들이 부채꼴로 펼쳐짐. 중앙 스핀들 + 방사형 카드
- 각 카드: 레퍼런스 이름 + 태그 색상 탭 + 한줄 설명
- 인터랙션: 회전 제스처로 카드 넘기기. 탭 클릭으로 카테고리 점프

**Full (전체 목록)**
- 부채꼴이 평면 그리드로 전환. 전체 검색/필터

### 꺼내기 행동

1. 카드를 Rolodex에서 "찢어내기" (미싱선 따라 떨어지는 애니메이션)
2. 책상 위에 놓으면 독립 카드로 정착
3. Rolodex 안에는 원본 유지 (다음에 열면 그대로)

### 장점
- 3소스 수렴 (가장 많은 독립 도출)
- "등록부" 성격과 정확히 일치
- 3-State 전환 자연스러움
- 구현 상대적으로 단순

### 단점
- 100개+ 스케일 한계 (회전 UX 느려짐)
- 레퍼런스 간 관계 시각화 불가
- 시각적 독창성 낮음 (친숙하지만 평범)

## 대안 옵션 5: Card Catalog Rail (카드 카탈로그 레일)

**순위**: 참고 (B클러스터)
**출처**: PM (Catalog Drawer) + Codex (Card Catalog Rail) 통합

### 은유

책상 한쪽 가장자리에 매입된 긴 서랍 레일. 도서관 카드 카탈로그의 수평 버전.

### 3-State 상세

**Covered**: 책상 가장자리의 얇은 라벨 바. 태그별 색상 구간 표시
**Spread**: 레일이 안쪽으로 슬라이드아웃. 카드 행 노출. 좌우 스크롤
**Full**: 레일이 넓어지며 전체 카탈로그 테이블 뷰

### 꺼내기 행동

레일에서 카드를 위로 "끌어올려" 책상 위에 놓기.

### 장점
- 공간 효율 최고 (가장자리만 사용)
- 대량 스케일에 강함

### 단점
- 캔버스 위 독립 entity라기보다는 가장자리 UI에 가까움
- 레퍼런스 간 관계 표현 불가
