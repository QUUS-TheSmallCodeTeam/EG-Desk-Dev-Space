# Desk Behaviors by Object Type

**작성일**: 2026-04-09
**상태**: brainstorming (UI/UX 시각화 중심)
**용도**: design-agent가 읽고 바로 화면을 그릴 수 있는 수준의 시각 묘사
**전제**: Mission Impossible 시점 (위에서 내려다봄), Surface-First, 3-State (Covered/Spread/Full)

---

## A. 브라우저 탭

### A-1. 단일 탭의 3-State

**Covered (썸네일 카드)**
- 외형: 약 120x80px 카드. 웹페이지 스크린샷이 카드 전체를 채움 (라이브 스냅샷, 5초마다 갱신). 좌상단에 파비콘 + 사이트명 라벨 (흰색 반투명 배경 위 텍스트). 우상단에 로딩 중이면 작은 회전 점.
- 질감: 카드 모서리 약간 둥글림. 그림자로 "책상 위에 놓인 사진" 느낌. 호버 시 카드가 1~2px 떠오르는 그림자 변화.

**Spread (뷰어)**
- 외형: 약 600x400px 패널. 상단에 주소 바 (URL 표시 + 파비콘). 중앙에 실제 웹페이지 렌더링 (라이브). 하단에 얇은 진행 바 (페이지 스크롤 위치).
- 인터랙션: 패널 안에서 스크롤, 클릭, 입력 가능. 패널 가장자리를 드래그하면 리사이즈.

**Full (전체화면)**
- 외형: 전체 viewport를 채움. 일반 브라우저처럼 동작. 상단에 미니멀 주소 바만 남음. ESC 또는 가장자리 스와이프로 Spread로 복귀.

---

### A-2. 여러 탭 그루핑 — "리서치 묶음"

**시나리오**: 유저가 React 공식문서, Stack Overflow 답변, GitHub 레포 3개의 브라우저 탭을 열어놓았음.

1. **묶기 (Bundle)**: 유저가 3개 Covered 탭 카드를 Shift+클릭으로 다중 선택 → 우클릭 "묶기" 또는 하나를 다른 둘 위로 천천히 드래그
   - 시각적 결과: 3장의 카드가 살짝 어긋나게 겹치며 하나의 묶음이 됨. 고무밴드 일러스트가 묶음을 감싸는 형태. 좌상단에 "3" 배지. 고무밴드 색상 = 유저가 지정 가능 (기본: 빨강).
   - 묶음 제목: 더블클릭으로 편집 가능 → "React 리서치" 라벨이 고무밴드 위에 표시.
   
2. **묶음 펼치기**: 묶음을 더블클릭 → 카드 3장이 부채꼴로 펼쳐짐 (120도 각도, 중심에서 방사형). 고무밴드가 늘어나며 연결선으로 변환 (탄성 있는 곡선).

3. **묶음 이동**: 묶음을 드래그하면 3장이 함께 이동. 고무밴드가 묶음을 유지.

4. **묶음 해제**: 고무밴드를 클릭 → "풀기" 버튼 → 고무밴드가 "툭" 끊어지는 애니메이션 → 카드 3장이 독립.

---

### A-3. 탭을 문서 옆에 배치 — 참조 관계 형성

**시나리오**: 유저가 API 문서 브라우저 탭을 PDF 스펙 문서 옆에 놓음.

1. 유저가 브라우저 탭 카드를 PDF 카드 가까이 (50px 이내) 드래그
2. 두 카드 사이에 은은한 회색 그림자 다리가 자동 생성 (Proximity Hint) — 반투명, 맥동하는 점선
3. 유저가 의도적으로 실(Thread)을 연결하고 싶으면: 탭 카드 가장자리의 작은 원형 포트를 드래그 → 빨간 실이 커서를 따라감 → PDF 카드의 포트에 놓으면 → 실선 연결 완성. 실 위에 "참조" 라벨 자동 생성.

---

### A-4. 탭 10개+ 관리

**시나리오**: 유저가 조사 중 탭을 12개 열었고 책상이 혼잡해짐.

1. **자동 정리 제안**: 탭이 8개를 넘으면 책상 하단에 은은한 파란 펄스 → "정리할까요?" 말풍선. 클릭하면 AI가 탭을 내용 기반으로 2~3개 묶음 제안 (예: "React 관련 5개", "배포 관련 3개", "기타 4개"). 각 묶음이 점선 원으로 미리보기됨.
2. **수동 Sweep**: 유저가 캔버스 빈 곳에서 오른쪽으로 세 손가락 스와이프 → 선택 안 된 탭들이 Peripheral zone으로 밀려남. Pinned 탭은 제자리 유지.
3. **탭 스택**: 같은 도메인 탭 여러 개 → 자동 감지하여 "스택 제안" 작은 팝오버 표시. 승인하면 같은 도메인 탭이 z-index 겹침으로 쌓임 (카드더미). 우상단에 개수 배지. 클릭하면 부채꼴 Fan Out.

---

### A-5. 탭 상태 변화 시각

**시나리오**: 백그라운드 탭에서 알림이 옴 (Slack 메시지, 이메일 도착 등).

- Covered 탭 카드의 가장자리에서 파문(ripple) 애니메이션 발생. 동심원이 카드 테두리에서 밖으로 퍼짐. 색상 = 알림 유형 (메시지=파랑, 에러=빨강, 완료=초록).
- 파문은 3회 반복 후 카드 우상단에 작은 점(dot) 배지로 변환되어 유지.

---

### A-6. 탭 닫기 vs 삭제

- **닫기** (X 버튼 또는 Cmd+W): 탭 카드가 책상 표면 아래로 서서히 가라앉는 애니메이션 (투명도 점진 감소 → 사라짐). 서랍으로 이동. Cmd+K → "최근 닫은 탭"에서 재소환 가능.
- **휴지통**: 탭 카드를 휴지통 entity로 드래그 → 카드가 구겨지는 애니메이션 → 휴지통 안으로 빨려들어감.

## B. 자료 (PDF, Excel, PPT, Word)

### B-1. PDF

**Covered (썸네일 카드)**
- 외형: 약 100x130px 세로형 카드 (실제 종이 비율). 첫 페이지 축소판이 카드 전체를 채움. 좌하단에 빨간 "PDF" 배지. 우하단에 페이지 수 (예: "24p"). 카드 우측 가장자리에 페이지 두께감 — 두꺼울수록 페이지 많음 (책 옆면처럼).

**Spread (뷰어)**
- 외형: 약 500x650px 세로형 패널. 현재 페이지가 크게 표시. 좌우 가장자리에 페이지 넘김 화살표 (반투명, 호버 시 불투명).
- 하단: 페이지 썸네일 스트립 (가로 스크롤). 현재 페이지 썸네일에 파란 테두리.
- 인터랙션:
  - 좌우 스와이프 또는 화살표로 페이지 넘김 — 종이 넘기는 애니메이션 (모서리가 접히며 넘어감)
  - 텍스트 드래그로 하이라이트 — 노란색 형광펜 효과
  - 하이라이트 영역 우클릭 → "메모 붙이기" → 해당 위치에 작은 포스트잇 생성

**Full (전체화면)**
- 전체 viewport. 좌측에 페이지 목차 사이드바. 상단에 검색 바.

**PDF 고유 행동**:
- 유저가 PDF Covered 카드를 다른 PDF 카드 위에 **천천히** 놓음 → "나란히 비교" 프롬프트 팝업. 승인하면 두 PDF가 좌/우로 나란히 Spread 상태로 펼쳐짐. 중앙에 얇은 구분선. 스크롤 동기화 토글 버튼.

---

### B-2. Excel / Spreadsheet

**Covered (썸네일 카드)**
- 외형: 약 130x100px 가로형 카드. 셀 격자 미리보기 (첫 시트의 A1~F10 영역 축소). 좌하단에 초록 "XLS" 배지. 하단에 시트 탭 미리보기 (색상 탭 2~3개 보임, 나머지는 "...").

**Spread (뷰어)**
- 외형: 약 700x450px 패널. 스프레드시트 격자 렌더링. 행/열 헤더 표시. 
- 하단: 시트 탭 바 (Sheet1, Sheet2...). 탭 클릭으로 시트 전환 — 시트가 옆에서 슬라이드인.
- 셀 클릭 → 상단에 수식 바 표시 (값 편집 가능).
- 우상단: 미니 차트 버튼 — 선택 영역의 인라인 차트 미리보기.

**Full (전체화면)**
- 전체 viewport. 리본 메뉴 간소화 버전 상단에 표시.

**Excel 고유 행동**:
- **비교 뷰**: 유저가 Excel 카드를 다른 Excel 카드 위에 놓음 → 두 스프레드시트가 좌/우로 Spread. 차이점이 있는 셀에 빨간 테두리 하이라이트 (diff 뷰). 상단에 "변경된 셀: 14개" 배지.
- **시트 분리**: Excel Spread 상태에서 시트 탭을 캔버스 밖으로 드래그 → 해당 시트가 독립 카드로 분리됨 (Split). 원본 Excel에서 해당 시트 탭이 회색(비활성)으로 변경.

---

### B-3. PPT / Presentation

**Covered (썸네일 카드)**
- 외형: 약 130x75px 가로형 카드 (16:9 비율). 첫 슬라이드 축소판. 좌하단에 주황 "PPT" 배지. 우하단에 슬라이드 수 (예: "18s"). 카드 하단 가장자리에 슬라이드 두께감.

**Spread (뷰어)**
- 외형: 약 650x400px 패널. 현재 슬라이드가 크게 표시.
- 하단: 슬라이드 썸네일 스트립 (가로 나열, 현재 슬라이드에 파란 테두리). 좌우 스크롤.
- 좌우 화살표로 슬라이드 넘김 — 슬라이드 전환 애니메이션 (좌에서 우로 슬라이드).
- 우하단: "발표 모드" 버튼 (Full로 전환 + 발표자 노트 오버레이).

**Full (전체화면)**
- 프레젠테이션 모드. 슬라이드가 viewport 전체. 하단에 슬라이드 진행 바. 발표자 노트는 작은 플로팅 패널.

**PPT 고유 행동**:
- **슬라이드 뿌리기**: PPT Spread 상태에서 "모든 슬라이드 펼치기" 버튼 → 슬라이드 18장이 책상 위에 카드로 흩뿌려짐 (Scatter 애니메이션). 각 슬라이드 = 독립 Covered 카드. 순서 번호 좌상단에 표시. 유저가 배치를 바꾸고 다시 "모으기" → 새 순서로 재조합.
- **슬라이드 추출**: 개별 슬라이드 썸네일을 스트립에서 캔버스로 드래그 → 독립 이미지 카드로 분리. 원본 PPT에는 슬라이드 유지.

---

### B-4. Word / Document

**Covered (썸네일 카드)**
- 외형: 약 100x130px 세로형 카드 (A4 비율). 첫 페이지 텍스트 미리보기 (흐릿하지만 레이아웃 인식 가능). 좌하단에 파란 "DOC" 배지. 우하단에 페이지 수.

**Spread (뷰어)**
- 외형: 약 550x650px 세로형 패널. 문서 텍스트 렌더링. 스크롤 가능.
- 우측: 미니맵 (전체 문서 축소 미리보기, 현재 위치 하이라이트).
- 좌측: 아웃라인 사이드바 (접기/펴기 가능). 헤딩 클릭 → 해당 위치로 스크롤 점프.
- 인라인 편집 가능: 텍스트 클릭 → 커서 활성화.

**Full (전체화면)**
- 전체 viewport. 워드프로세서 뷰. 상단 간소화 툴바.

**Word 고유 행동**:
- **인용 연결**: Word Spread 상태에서 텍스트를 선택 → 드래그하여 캔버스의 다른 문서(PDF 등)에 놓음 → 인용 실(Thread)이 생성됨. 실선, 라벨 "인용". Word 쪽에 인용 마커(작은 책갈피 아이콘), PDF 쪽에 참조 마커.

---

### B-5. 자료 간 상호작용

**문서 + 브라우저 탭**:
- 유저가 브라우저 탭 카드를 Word 문서 Spread 위로 드래그 → Word 문서 가장자리가 파란 글로우로 하이라이트 → 놓으면 "링크 삽입" 또는 "참조 연결" 선택 팝업. "참조 연결" 선택 시 → 문서 하단에 참조 목록 항목 추가 + 두 객체 사이 Thread 생성.

**PDF → Excel**:
- 유저가 PDF의 표(table) 영역을 드래그 선택 → 선택 영역이 파란 점선 박스로 하이라이트 → 이 박스를 캔버스 빈 곳에 드래그 → "표 추출" 애니메이션 (데이터가 PDF에서 "떨어져 나오며" 새 Excel 카드 생성). Excel 카드가 추출된 표 데이터를 포함.

**PPT → Word**:
- PPT 슬라이드 카드를 Word 카드 위에 놓음 → "슬라이드를 문서에 삽입할까요?" 팝업 → 승인 시 Word 문서에 슬라이드 이미지 삽입. 두 객체 사이 "포함" Thread 생성 (점선, "embedded" 라벨).

## C. 메모 행위

### C-1. 독립 메모 생성

**시나리오**: 유저가 빈 캔버스에서 빠른 메모를 남기고 싶음.

- 캔버스 빈 곳을 더블클릭 → 작은 포스트잇이 "팝" 하고 나타남 (스케일 0 → 100% 바운스 애니메이션). 
- 기본 크기: 약 120x120px. 노란 배경 (6가지 색상 선택 가능: 노랑/분홍/파랑/초록/보라/주황).
- 즉시 텍스트 입력 모드 활성화 (커서 깜빡임).
- 입력 완료 후 캔버스 다른 곳 클릭 → 메모 확정. 메모 크기가 내용에 맞게 자동 조절 (최소 80x80, 최대 200x200).

### C-2. 객체에 메모 부착

**시나리오**: 유저가 PDF에 코멘트를 붙이고 싶음.

1. 메모 카드를 PDF Covered 카드 위로 드래그
2. PDF 카드 가장자리가 노란 글로우 (메모 색상) → "부착 가능" 시각 단서
3. 놓으면 → 메모가 PDF 카드의 우상단 모서리에 "꽂힘". 메모 크기가 약 60x60px로 축소. 메모의 약 30%가 PDF 카드 밖으로 삐져나옴 (실제 포스트잇처럼).
4. PDF를 이동하면 → 메모도 함께 이동 (부착된 상태).
5. 메모를 PDF에서 떼려면 → 메모를 길게 누르고 밖으로 드래그 → "찢기" 미세 진동 피드백 → 독립 메모로 복귀.

**부착된 메모의 3-State 연동**:
- PDF가 Covered일 때: 메모는 축소판으로 모서리에 삐져나옴
- PDF가 Spread일 때: 메모가 펼쳐지며 전체 내용 표시. PDF 뷰어 우측에 말풍선처럼 위치
- PDF가 Full일 때: 메모가 플로팅 패널로 변환 (드래그 가능)

### C-3. 메모로 화살표 연결 — 관계 표기

**시나리오**: 유저가 "이 PDF의 3장 내용이 이 Excel의 B열과 관련있다"를 표현하고 싶음.

1. 메모를 하나 생성하고 "PDF 3장 → Excel B열 매핑" 작성
2. 메모의 좌측 가장자리에 작은 원형 포트(커넥터)가 나타남 (호버 시 표시)
3. 포트를 드래그 → 빨간 화살표가 커서를 따라감 → PDF 카드에 놓으면 연결
4. 메모 우측 포트에서도 화살표 드래그 → Excel 카드에 연결
5. 결과: 메모가 PDF와 Excel 사이에 위치하며, 양쪽으로 빨간 화살표가 연결됨
6. 화살표 색상: 빨강(기본), 파랑(참조), 초록(승인), 노랑(질문) — 화살표 우클릭으로 변경

**시각적 결과**: 위에서 내려다보면 수사 보드의 빨간 실 + 핀 형태. 메모 = 핀에 꽂힌 카드, 화살표 = 실.

### C-4. 플로우차트 구성

**시나리오**: 유저가 프로젝트 프로세스를 메모와 화살표로 시각화.

1. 메모 5개 생성: "기획" → "디자인" → "개발" → "테스트" → "배포"
2. 각 메모를 가로로 배치 (Align 행동으로 일렬 정렬)
3. 메모 간 화살표 연결: "기획"→"디자인"→"개발"→"테스트"→"배포"
4. 각 메모 아래에 관련 자료 부착: "기획" 아래에 Word 스펙문서, "디자인" 아래에 PPT 시안, "개발" 아래에 브라우저 탭(GitHub), "테스트" 아래에 Excel 테스트케이스

**시각적 결과**: 위에서 내려다보면 가로 플로우차트. 각 단계 메모가 노드, 화살표가 엣지. 각 노드 아래에 관련 자료가 클러스터링. 전체가 하나의 작업 맵처럼 보임.

### C-5. 메모 색상과 필터링

- 메모 색상별 의미: 유저가 자유롭게 정의 (예: 노랑=TODO, 분홍=질문, 파랑=결정, 초록=완료)
- Cmd+K → "분홍 메모만 보기" → 분홍 메모만 밝게, 나머지 모든 객체 Dim (Spotlight 효과)
- 분홍 메모들이 빛나며 한눈에 "열린 질문들" 파악 가능

### C-6. 빠른 캡처 vs 구조화 메모

**빠른 캡처**: 
- Cmd+N 어디서든 → 커서 위치에 작은 메모 팝업. 타이핑 후 Enter → 확정. 가장 가까운 객체에 자동 부착 (50px 이내 객체가 있으면).

**구조화 메모 (Binder)**:
- 여러 메모를 선택 → 우클릭 "바인더로 묶기" → 메모들이 노트북 형태로 합쳐짐. 바인더 = Document 객체 유형. Spread하면 메모들이 페이지 형태로 나열.

---

## D. 채팅 (에이전트 인격화 + 프로젝트/그룹 채팅) 연계

### D-0. 메신저 객체의 3-State

**Covered (채팅 카드)**
- 외형: 약 100x80px 카드. 좌측에 에이전트 아바타 (원형, 에이전트별 고유 색상 + 이니셜). 우측에 마지막 메시지 미리보기 (1줄). 하단에 시간 스탬프.
- 미읽은 메시지 있으면: 아바타 우상단에 빨간 점 배지 + 카드 가장자리에서 은은한 파란 펄스.
- 프로젝트 채팅이면: 아바타 대신 프로젝트 아이콘 (폴더+사람들). 참여자 수 배지.

**Spread (채팅 뷰어)**
- 외형: 약 350x500px 세로형 패널. 상단에 에이전트 이름 + 아바타 + 상태 (온라인/오프라인/처리중). 중앙에 대화 내역 (말풍선 형태). 하단에 입력 바.
- 에이전트 말풍선: 좌측 정렬, 에이전트 색상 연한 배경.
- 유저 말풍선: 우측 정렬, 회색 배경.
- 에이전트가 처리 중일 때: 말풍선 위치에 타이핑 인디케이터 (점 3개 펄스).

**Full (전체화면)**
- 전체 viewport. 좌측에 채팅 목록 사이드바 (다른 에이전트/프로젝트 채팅 목록). 중앙에 대화. 우측에 공유된 자료 패널.

---

### D-1. 에이전트에게 자료 넘기기 (Context Toss)

**시나리오**: 유저가 PDF를 에이전트 "분석봇"에게 넘겨서 요약을 요청.

1. 유저가 PDF Covered 카드를 에이전트 채팅 카드 위로 드래그
2. 채팅 카드에 진입하는 순간: 에이전트 아바타 주변에 **파란 흡입 원**(반경 약 60px)이 나타남. 원이 천천히 맥동 (수축/확장). 아바타 안쪽으로 미세한 입자(particle)가 흘러들어가는 효과.
3. PDF를 놓으면: PDF 카드에서 **빛나는 실(thread)**이 에이전트 아바타로 연결됨. 실 색상 = 에이전트 고유 색상. 실이 데이터 전송을 나타내듯 **빛 입자가 실을 따라 PDF → 에이전트 방향으로 흐름** (1~2초).
4. 전송 완료 후: 채팅 패널(Spread) 안에 "PDF가 공유됨" 시스템 메시지 + PDF 미니 썸네일. 에이전트가 자동 응답: "문서를 분석합니다..." (타이핑 인디케이터).
5. PDF 카드 자체는 책상 위에 그대로 남음 (사본이 전송된 것). PDF 카드 좌하단에 작은 에이전트 아바타 배지 추가 → "이 에이전트가 읽은 적 있음" 표시.

---

### D-2. 에이전트 처리 중 시각적 표현

**시나리오**: 에이전트가 넘겨받은 PDF를 분석 중.

1. **에이전트 채팅 카드(Covered)의 변화**: 
   - 에이전트 아바타 테두리에 **회전하는 글로우 링** (에이전트 색상). 시계 방향 회전.
   - 카드 하단에 진행 바 (불확정적이면 좌우 왕복 애니메이션, 확정적이면 0→100% 채워짐).
   
2. **연결된 PDF 카드의 변화**:
   - PDF 카드에서 에이전트로의 실(thread)이 계속 빛 입자를 흘려보냄 (처리 중 지속).
   - PDF 카드 자체에 미세한 **스캔라인 효과** — 위에서 아래로 얇은 빛줄이 이동 (에이전트가 문서를 "읽고 있음"을 시각화).

3. **처리 완료**: 
   - 글로우 링이 "완료 펄스" (한번 크게 확장 후 소멸).
   - 실의 빛 입자 흐름 중단. 실이 정적 연결선으로 변환.
   - 채팅 안에 결과 메시지 도착.

---

### D-3. 에이전트가 결과물을 책상에 놓기

**시나리오**: 에이전트가 PDF 분석 완료 후 요약 문서를 생성.

1. 채팅 Spread 패널 안에 에이전트 말풍선: "분석 완료. 요약 문서를 생성했습니다." + 문서 미니카드 (Covered 축소판).
2. 유저가 말풍선 안의 미니카드를 **채팅 패널 밖(캔버스)으로 드래그**.
3. 미니카드가 채팅 패널 경계를 넘는 순간: **에이전트 아바타에서 빛나는 실이 새 카드로 연결** + 카드가 스케일 50% → 100%로 확대 애니메이션 ("실체화").
4. 책상 위에 새 Word 카드 정착. 에이전트 아바타 배지가 카드에 표시 ("이 에이전트가 생성함").
5. 원본 PDF와 새 요약 문서 사이에 자동 Thread 생성 (점선, "요약" 라벨).

**대안 행동 — 자동 배치**: 에이전트 설정에서 "결과물 자동 배치" 활성화 시 → 에이전트가 생성한 문서가 원본 PDF 바로 옆에 자동 출현. 출현 애니메이션: 원본 PDF에서 빛이 번지며 옆에 새 카드가 "자라남".

---

### D-4. 문서를 채팅에 드래그 = "이거 분석해줘"

**시나리오**: 유저가 Excel 파일을 프로젝트 채팅에 공유하며 토론 시작.

1. 유저가 Excel 카드를 프로젝트 채팅 카드 위로 드래그
2. 프로젝트 채팅 카드에 진입하면: 채팅 카드가 살짝 확대 (1.05x) + 테두리에 초록 글로우 ("수신 가능").
3. 놓으면: 채팅이 자동으로 Spread 상태로 열림. 대화창에 "Excel이 공유됨" + 미니 썸네일. 입력 바에 커서 자동 포커스 → 유저가 코멘트 입력 ("이 매출 데이터 분석해줘").
4. 에이전트가 분석 중: 채팅 안에서 에이전트 아바타 옆에 처리 인디케이터 + Excel 미니 썸네일에 스캔라인 효과.
5. 결과: 에이전트가 차트 이미지 + 요약 텍스트를 말풍선으로 반환. 차트를 캔버스로 드래그 가능.

---

### D-5. 프로젝트 채팅에서 여러 자료 토론

**시나리오**: 프로젝트 채팅 "Q4 기획"에서 팀이 PDF 보고서 + Excel 데이터 + PPT 초안을 토론 중.

**채팅 Spread 상태의 "공유 자료 패널"**:
- 채팅 Spread의 우측에 세로 패널: 이 채팅에서 공유된 모든 자료가 미니 카드로 나열.
- 각 미니카드: Covered 축소판 + 공유한 사람 아바타 + 공유 시간.
- 미니카드를 클릭하면 → 채팅 Spread 옆에 해당 자료가 Spread로 나란히 열림 (자동 리사이즈).
- 미니카드를 캔버스로 드래그하면 → 독립 Covered 카드로 책상 위에 배치.

**채팅 안에서 자료 참조**:
- 대화 중 "@보고서.pdf 3페이지" 타이핑 → 자동 링크. 클릭하면 PDF가 3페이지로 점프하며 Spread.
- 에이전트가 "Excel B3:B15 영역을 참조하면..." 응답 → 해당 영역이 하이라이트된 Excel 미리보기 인라인 삽입.

---

### D-6. 이중 인터페이스 — 사용자 vs 에이전트의 객체 읽기

**핵심 원칙**: 같은 객체를 사용자는 "시각적으로" 보고, 에이전트는 "의미적으로" 읽는다. 이 차이를 시각적으로 표현.

**사용자가 PDF를 펼칠 때 (Spread)**:
- 페이지 뷰어. 시각적 레이아웃 보존. 하이라이트, 페이지 넘김.

**에이전트가 PDF를 읽을 때**:
- PDF 카드에 스캔라인 효과 (위→아래 빛줄 이동).
- 에이전트 채팅 안에서: 추출된 텍스트가 타이핑 애니메이션으로 나타남. 핵심 문장에 자동 하이라이트.
- 채팅 패널 하단에 "에이전트 시점 토글" 버튼: 누르면 PDF Spread가 "에이전트 뷰"로 전환 — 텍스트만 표시 + 핵심 문장 하이라이트 + 추출된 구조(헤딩, 표, 목록) 아웃라인.

**에이전트가 브라우저 탭을 읽을 때**:
- 브라우저 탭 카드에 그리드 오버레이 (DOM 구조 시각화 — 블록 요소가 연한 파란 윤곽선으로 표시).
- 에이전트 채팅 안에서: "페이지 구조 분석 중..." → 주요 콘텐츠 영역, 네비게이션, 사이드바가 라벨링된 와이어프레임 축소판.

**시각적 구분**: 
- 사용자 조작 = 직접적 (클릭, 드래그, 스크롤)
- 에이전트 처리 = 빛/입자 효과 (스캔라인, 입자 흐름, 글로우)
- 항상 사용자의 시각적 뷰를 방해하지 않음 — 에이전트 효과는 미세하고 비침투적.

---

### D-7. 에이전트 아바타의 책상 위 존재

**시나리오**: 에이전트 "분석봇"이 채팅이 아닌 캔버스 위에 독립 entity로 존재.

- 에이전트 아바타: 약 50x50px 원형. 에이전트 고유 색상 테두리. 중앙에 이니셜 또는 아이콘.
- **유휴 상태**: 아바타가 약간 투명 (70% opacity). 미세한 호흡 애니메이션 (크기 0.98~1.02 맥동).
- **활성 상태** (처리 중): 아바타 불투명 + 글로우 링 회전.
- **결과 대기**: 아바타에서 작은 말풍선 아이콘 (결과가 있음 알림).

**자료 전달**: 아무 객체를 에이전트 아바타 위로 드래그 → 흡입 원 + 실 연결 (D-1과 동일). 채팅 패널이 없어도 에이전트에게 직접 전달 가능. 결과는 아바타 옆에 새 카드로 출현하거나, 아바타 클릭 시 채팅 Spread로 확인.

## 부록: 행동 조합 예시 (Cross-Object)

| 행동 조합 | 시각적 결과 |
|-----------|-----------|
| PDF + PDF 겹치기 | 나란히 비교 뷰 (좌/우 Split Spread) |
| Excel + Excel 겹치기 | Diff 비교 (변경 셀 빨간 테두리) |
| 아무 객체 → 에이전트 아바타 드래그 | 흡입 원 + 빛 실 연결 + 분석 시작 |
| 아무 객체 → 채팅 드래그 | 채팅에 공유 + 코멘트 입력 유도 |
| 메모 → 객체 위 드래그 | 포스트잇 부착 (삐져나옴) |
| 메모 포트 → 객체 드래그 | 화살표 연결 (관계 표기) |
| 브라우저 탭 → Word 위 드래그 | 참조 링크 삽입 또는 Thread 연결 |
| PPT "슬라이드 펼치기" | 모든 슬라이드가 독립 카드로 Scatter |
| 묶음(Bundle) 드래그 → 에이전트 | 묶음 전체를 context로 전달 |
| Flag(빨강) + Gather | 빨간 깃발 객체만 Focus zone으로 모임 |
