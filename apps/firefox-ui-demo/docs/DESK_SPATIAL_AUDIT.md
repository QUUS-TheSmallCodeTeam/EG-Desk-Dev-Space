# 2D 작업면의 렌더 판정: 무엇이 놓였고, 무엇이 실제로 닿는가

공간상의 배치, 화면에 그려진 결과, 입력을 받을 수 있는 상태는 서로 다른 사실이다. 합성 Firefox에서 공용 Board 하나를 검사하는 첫 적용 범위와 Desk 전체·제품 Agent로 확장하는 설계를 구별한다. 아래 규칙은 기존의 모든 Canvas 요소에 이미 구현된 전역 규격을 인용한 것이 아니다.

## 판정 단위

1. **월드와 뷰포트.** 저장된 창의 월드 `x,y,w,h`는 사용자 책상의 자리다. 검사에서는 현재 카메라가 적용된 같은 순간의 화면 CSS 픽셀 `getBoundingClientRect()`끼리 비교한다. 카드의 사각형이 겹친다는 것은 기하 정보다. 보드 바탕이 소속 카드를 둘러싸거나 사용자가 전표를 포갰다고 오류를 내지 않는다. 겹침이나 거리로 소속·업무 관계도 추론하지 않는다.
2. **보이는 범위.** 화면 밖, 일부만 화면 안, 스크롤·`overflow` 조상 경계에 잘림, 숨김·접힘을 구별한다. 화면 밖 요소를 다른 창이 가린 것으로 보고하지 않는다. 경계 상자 교차만으로 조작할 수 있다고 판정하지 않는다.
3. **입력 도달성.** 창 전체와 주요 조작점은 별도 대상이다. Firefox의 `elementFromPoint`로 화면 내 표본에서 목표 또는 그 자손이 실제 입력을 받는지 본다. 제목줄은 살아 있어도 ‘회신’은 안 눌릴 수 있다. 클릭을 통과시키는 시각 오버레이와 불투명도, CSS z-index 숫자만으로 실제 가림을 판정하지 않는다. 샘플 hit는 접근 가능한 조작점의 증거이지, 보이는 픽셀 면적·가림 비율이나 실제 클릭 성공을 보증하지 않는다. 키보드 접근성도 별도다.
4. **근거와 행위.** ‘사각형 교차’는 정보, ‘동작 버튼의 유효 표본에서 타깃을 한 번도 맞히지 못함’은 조사할 경고, ‘확인할 수 없음’은 미측정이다. 어느 경우도 사용자의 배치 변경·창 올리기·스크롤·자동 클릭 승인이 아니다. 관련 없는 개인 창은 검사 결과에 식별자로 남지 않는다.

## 한 장면을 읽는 예 (설명 예시, 실측 로그 아님)

‘자료 A와 B의 화면 사각형이 겹침’과 ‘A의 회신 버튼에서 유효 표본 9개 중 0개만 목표에 닿음’은 독립된 사실이다. 후자는 ‘측정한 지점에서는 회신 버튼이 입력을 받지 못했다’까지 말할 수 있다. ‘A의 100%가 안 보임’, ‘B가 업무 선행 조건’, ‘두 카드를 자동으로 옮겨야 함’은 근거 밖이다. 창 A만 읽도록 허가된 호출자에게 B의 존재·이름·종류·좌표·개수를 알려주지 않는다.

## 제품/QA/Agent 경계

- `DESK_AGENDA_CARD_RUNTIME_MODEL.md`의 *Viewport and Zoom Coordinates*와 `VIEWPORT_LAYOUT_INTERACTION_MODEL.md`의 *Placement Operations*는 좌표/배치 기준이다. 배치 엔진 `EGDeskCanvasLayout.sys.mjs`의 `arrangeWithoutOverlap`은 **명시적 배치 명령**이다. 검사 API가 아니다.
- `scripts/verify-firefox-mcp-headless-ui-regression.mjs`의 `observeReachabilityDockPoint`는 과거의 직접적인 구현 선례다. Chat Dock 버튼의 조상 클리핑과 3×3 포인터 도달성을 검사하는 **QA 도구**다. 제품 Agent가 Desk 전체를 볼 수 있다는 뜻이 아니다.
- 공용 Board의 이번 로컬 검사는 해당 프로필에서 읽을 수 있고 실제 마운트된 창만 다룬다. 한 번의 관찰 안에서만 유효한 기호를 쓰고, 제목·본문·브라우저 화면·키·권한 없는 방해물의 신원은 출력하지 않는다. 결과는 관찰 순간에만 해당한다. 퍼센트 가시성, 브라우저 내부 DOM, 다른 사람의 화면, 상대의 배치를 반환하지 않는다.
- 제품 모델 자동 전송은 **없다**. 나중에 Agent가 이를 조회하려면 `누가 / 어느 projection / 어떤 소스 / 어떤 목적·기한`을 별도 읽기 권한으로 확인하고, 수집 전과 반환 전에 같은 권한을 재검사해야 한다. 협업 보드 참여나 모델 옵션을 그 권한으로 대신하지 않는다. 범용 privileged `evaluateChrome`은 격리된 QA 전용이다.

AI가 표식을 **만드는** 기존 설계는 [AI Canvas Annotation Layer: Core Idea / Coordinate Model / Agent Workflow](./AI_CANVAS_ANNOTATION_LAYER.md#core-idea)에 있다. 대상 카드 내부의 정규화 좌표로 받은 구조를 편집 가능한 도형으로 렌더하는 계약이다. 2D 작업면을 **읽고** 어떤 사실까지 보고할 수 있는지와는 별도의 방향이다. 이번 검사는 이 읽는 방향을 보강한다.
