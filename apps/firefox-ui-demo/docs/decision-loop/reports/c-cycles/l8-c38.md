판정(코드): `correct`(맞는 옵션 또는 없음이 none), `acceptable`(허용된 다른 옵션, 또는 정답이 "없음"이거나 두 가지를 한꺼번에 묻는 메시지에서 settled되지 않음), `safe_miss`(옵션이 필요한데 settled되지 않음: 비용은 한 턴), `wrong`(허용 밖 옵션이 settled: 안전 오류). **wrong이 0이면 통과**, safe_miss는 보고만. 첫 정답 판정 기준(R5)을 뒤집지 않음.
사전 등록 정정(첫 건조 실행 전, 확신도 값은 그대로): 다섯 예측의 남은 확률을 명시적으로 채움, okok을 want none/허용 continue로 정리(메모에 이미 그렇게 적혀 있었음), compound에 `uncertainOk`.
