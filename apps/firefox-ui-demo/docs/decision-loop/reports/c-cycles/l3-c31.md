# L3 사이클 31 — 고정 문구 감사와 FLOW_COPY.stalled의 선택지 (다)

- 브랜치 `lane/c31-fixed-copy-audit` (int/c14 `ab4d121` 위). 부록: `l3-c31-appendix-copy-audit.md`, 전체 목록 `l3-c31-copy-audit-full.tsv`.

## 1. 선택지 (다) 구현: 쓰기 모델이 실패하면 아무것도 보내지 않는다
- 기존 설정 `conversationFlow` 에 `stalledCopy()` 를 더했다. `'none'` 이면 엔진이 멈춘 것으로 보이는데 쓰기 모델이 6초 안에 문장을 못 썼을 때 **아무것도 게시하지 않는다**. 기본(없음 또는 `'fixed'`)은 지금과 같다: 고정 문장 `FLOW_COPY.stalled` 한 번. 새 사용자 문구 없음.
- 브리지: 환경변수 `EGDESK_FLOW_STALLED_COPY=none` (EGDESK_CONVERSATION_FLOW=on 과 함께). 소유자가 (다)를 고르면 이 값을 켜면 되고, (가)는 아무것도 안 바꾸고, (나)는 `FLOW_COPY.stalled` 한 줄 교체다.
- 테스트: 기본/`fixed` 는 고정 문장, `none` 은 0개이고 최종 답은 그대로 온다; 브리지의 환경 연결; 변이 3건(none 무시, none을 기본으로, 브리지 미연결)이 잡혔다.

## 2. 감사 결과 (부록 한 장으로 결정 가능)
기준 시점은 루프 직전 커밋. 채팅 경로 파일 16개의 한글 문자열 3,380개 중 **3,303개는 기존 제품 UI**(루프 이전, 바꾸지 않음), **77개가 루프에서 추가**됐다. 77개의 내역:
- **A. 채팅 말풍선·실행 기록 줄에 기본으로 보이는 것 6개** — `FLOW_COPY.stalled`(말풍선), `접수 여부를 확인하지 못했습니다. 자동으로 다시 보내지 않습니다.`(보내기 오류 줄), 실행 기록 줄 `기억 자료 N개`, `기록 확정 1건`, `기록 취소 1건`, `도구 결과 정리 · N건 · M줄 생략`. 이 6개가 **N1의 승인 대기 문구**다.
- **B. 숨겨진 [보기 추천] 기능의 문구 41개** (`EGDESK_CHAT_CHOICE=on` 일 때만 보임; 브리지 607행: 소유자 결정까지 숨김). 기능을 켜기로 하면 같이 결정한다.
- **C. 채팅 밖(Board 정리 제안 알림, 배치 제안, 설정의 키 확인 줄, Board Agent 질문, 질문·발췌 전송 안내, 브리핑 이름) 30개** — N1 범위 밖이지만 같은 승인 대기.
소스의 "pending approval" 표식 5곳(`FLOW_COPY`, `기억 자료`, `기록 확정/취소`, 작업 기억 줄, Board 정리 알림)은 모두 표에 있다. 승인된 문구 장부는 저장소에 없다(LEDGER/PHILOSOPHY에는 승인 대기만 있음). 그래서 "승인됨"으로 표시한 문구는 없고, 기존 UI는 "루프 이전, 변경 없음"으로 구분했다.

한계: 한글 문자열 리터럴만 추출했다(영어 문구, 여러 줄로 나뉜 문자열, 동적으로 조립되는 문구는 놓칠 수 있다). 모델에게 주는 영어 지시와 영어 API 오류는 사람에게 보이지 않아 제외했다.
