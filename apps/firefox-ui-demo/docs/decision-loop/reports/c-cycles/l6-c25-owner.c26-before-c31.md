# 다음에 무엇을 켤 수 있고, 얼마나 드는가 (owner 용 한 장, L6 c26 갱신판)

**한 줄 결론**: 지금 켜도 되는 것 2개 (A), 문구 결정 하나로 켤 수 있는 것 1개 (B), 재측정 한 번이면 되는 것 1개 (C), 아직 켜면 안 되는 것 2개 (D), 개발자 플래그 1개 (E). 모든 플래그는 지금 꺼져 있고, 켤지는 당신이 정합니다.
**읽는 법**: 비용은 Decisions 입력 토큰 (한 턴 평균, 모델 추정). 같은 입력을 되풀이한 실행은 증거로 세지 않았습니다 (같은 요청은 같은 답이 나옴: 117쌍 중 117쌍). 그래서 "통과 몇 번" 은 새 입력으로 통과한 횟수입니다.

**시나리오 A. 지금 켜도 됨 — `WORK_PLACEMENT` + `PRESENCE`**
- 사람이 느끼는 것: 내가 다른 화면을 보고 있을 때 끝난 결과가 어디에 있는지 짧게 알려 줍니다.
- 비용: 한 턴 약 +50 토큰. 위험: 낮음 (여러 번의 전체 실행에서 문제 없음). 모자란 것: 없음.

**시나리오 B. 문구 하나만 정하면 켤 수 있음 — `CONVERSATION_FLOW`**
- 사람이 느끼는 것: 긴 명령이 도는 동안 "아직 실행 중" 이라는 짧은 안내가 나가고, "왜 멈췄니?" 하면 별도 답이 바로 옵니다 (실제 엔진에서 따로 게시되는 것 확인).
- 비용: 한 턴 약 +470 토큰 (요청 +0.8개). 위험: 낮음 (안내가 없던 자리에 메시지가 생길 뿐).
- 모자란 것: **하나, 고정 문장의 승인.** 글쓰는 모델이 못 썼을 때만 나가는 "응답이 평소보다 오래 걸리고 있습니다. 더 기다리거나, 중지하고 다시 요청할 수 있습니다." 를 (가) 그대로 쓸지 (나) 고칠지 (다) 없애고 그때는 아무것도 안 보낼지. 증거와 코드는 준비되어 있습니다.

**시나리오 C. 재측정 한 번이면 켤 수 있음 — `BROWSER_ENTRY`**
- 사람이 느끼는 것: "포털에서 세금계산서 받아줘" 같은 말을 하면 채팅이 말로만 답하지 않고 허용된 브라우저 카드에서 일을 시작합니다. 로그인이나 선택이 필요하면 채팅으로 한 번 물어보고 멈춥니다 (실험에서 사람 몰래 행동한 적 없음).
- 비용: 한 턴 약 +1,170 토큰 (요청 +1.0개, 입장 판단 약 340 ms). 위험: 시작하지 말아야 할 때 시작하는 것. 측정: 입장 판단 20요청에서 hard 오류 0, 행동 금지 항목 전부 통과.
- 모자란 것: **settings 계획을 지금 코드로 한 번 더 돌려 보는 것 (약 3k 토큰).** 마지막으로 실패한 인계 단계는 고쳐진 것으로 보이지만 (다른 계획에서 통과) 그 계획 자체는 다시 안 돌렸습니다. 그리고 지금 본문으로 끝까지 간 새 실행은 하나뿐입니다.

**시나리오 D. 아직 켜면 안 됨 — `DRAFT_CHECK` (그리고 같은 이유로 `CONTEXT_RELEVANCE=action`)**
- 사람이 느끼는 것: 저장된 기록과 어긋나는 답 (예: 아직 안 했는데 "배포 완료") 을 올리기 전에 고치거나 막습니다. **좋아진 것**: 최근 실행에서 거짓 "배포 완료" 가 더는 올라가지 않습니다. **남은 문제**: 근거를 못 찾으면 맞는 답도 막힙니다. 최근 실행에서 맞는 "12월 첫째 주 예정" 이 올라가지 않았고, 사람은 그 턴에 답을 받지 못합니다.
- 비용: 한 턴 약 +660 토큰. 위험: **높음 (말 없이 답이 사라질 수 있음).**
- 모자란 것: 맞는 답이 막히는 경우의 수정과, 새 입력 (다른 말투, 다른 페이지 묶음) 에서의 확인 (곧 보낼 변형 V1 이 처음 재 줍니다). 지금까지 "수정 후 통과" 는 같은 입력의 반복이라 증거가 아닙니다.

**시나리오 E. 개발자 플래그, 기본 꺼짐 — `TURN_MEMORY_ENGINE_CONTEXT=split`**
- 사람이 느끼는 것: 긴 기억을 참조한 답에서 가운데 내용 (금액, 담당자, 시각) 이 빠지지 않습니다. 켜지 않으면 엔진이 큰 항목의 가운데를 잘라서 사실을 잃습니다 (실제 엔진: 분할 없이 사실 3개 유실, 분할 켜면 4개 모두 답에 있음, 가장 큰 조각 3,972 B).
- 비용: Decisions 0, 엔진 입력이 큰 기억이 있는 턴마다 약 +1.9k~2.3k 토큰. 위험: 중간 (초안 검사와 함께 켠 실행이 없음).
- 모자란 것: 여정에서의 실행 (지금은 규모 대화 하나와 크기 probe 둘이 전부), 초안 검사와 함께 켠 실행, 비용에 대한 당신의 판단.

**합계**: A+B+C 를 모두 켜면 한 턴 약 +1,700 토큰 (기억 포함 기준선 약 6.3k → 약 8.0k). D 는 위험 때문에 뺐고, E 는 Decisions 비용이 없습니다.
**다음**: 변형 V1 실행 (수정 뒤, 새 입력) 의 결과가 D 의 판단을 정합니다. C 는 settings 재측정을 허락하시면 됩니다. B 는 문구만 정해 주시면 됩니다.
