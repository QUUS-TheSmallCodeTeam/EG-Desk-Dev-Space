## 2. A1: 이미 가진 기억 자료를 초안 점검의 근거로

- **재현**: 수정 전 `EGDESK_ALL_ON_REPRO=1` 로 A1 이 실패했다 (`no rewrite turn: 1 !== 0`).
- **원인**: 두 번째 턴에는 새로 붙는 자료가 없다. 그래서 초안 점검의 근거가 비고, 맞는 답이 다시 쓰기로 갔다.
- **수정**: `memoryEvidence()` (`egdesk-turn-memory.mjs`) 를 추가했다.
  - `memoryMaterials` 와 같은 페이지를 같은 권한 확인으로 고른다: 이번 턴에 붙인 것과 이 스레드가 이미 가진 것.
  - 초안 점검의 근거 항목 형태 `{ id, kind, time, status, source, text }` 로 낸다.
  - 자기 권한이 걸린 페이지 (동의에 묶인 발언·대화, `mayRead` 페이지) 는 내용 없는 참조(`opaque`)로만 넣는다. 런타임의 점검용 게이트에는 speech 권한이 없기 때문이다.
  - 나머지는 `kind: 'memory'` 로 넣고, `egress.filterEvidence` 가 memory 권한을 확인한다.
- **L3 영역 diff**: `noteDraftCheckTurn` 매개변수 하나, `draftCheckTurns` 의 `memory` 필드 하나, 답변 점검 호출 두 곳의 `...(turn.memory ?? [])`.
- **처음 고친 것을 되돌린 부분**: 처음에는 기억 근거를 모든 점검에 넣었다. 그러자 heartbeat 의 중간 메시지 점검에도 들어가서 Decision 요청이 1건 늘었다. 중간 메시지는 실행 상태에 관한 것이라 답변 점검에만 넣도록 바꿨다. 전체 여정 테스트가 그대로 통과한다.
- **확인**: 수정 후 A1 이 통과해서 건너뜀을 풀었다. 수정을 빼면 다시 실패한다. 여정 테스트의 A1 주석도 사실에 맞게 고쳤다 (L2 파일, 주석만).

## 3. A3: 브리지 배선

- 개발자 플래그 셋 (환경 변수, 시작 때 한 번 읽음, 사용자에게 보이는 이름 아님):
  - `EGDESK_TURN_MEMORY_ONE_PACKET=on`
  - `EGDESK_TURN_MEMORY_WRITE_TARGET=choice`
  - `EGDESK_TURN_MEMORY_CONFIRM=on`
- 설정하지 않거나 다른 값이면 기본값이다. 매핑은 `turnMemoryFlagsFromEnv` (wiring 모듈) 하나이고, 브리지가 `createTurnMemoryConfig({ ..., ...turnMemoryFlagsFromEnv(process.env) })` 로 쓴다.
- 테스트:
  - 매핑 자체 (정확한 값만 켬)
  - 브리지 소스가 그 호출을 정확히 한 번 쓰는지
  - 그렇게 만든 설정이 실제 런타임에 닿는지 (묶음 하나, 쓰기 대상 설계, 확인 흐름)
- 변이 확인: 브리지에서 펼침을 빼면 테스트가 실패한다.
- L2 하네스의 `onePacket` 옵션도 같은 플래그를 거치게 바꿨다. 여정의 한 묶음 테스트는 이제 `env: { EGDESK_TURN_MEMORY_ONE_PACKET: 'on' }` 으로 돈다. 기본(플래그 없음) 에서는 여전히 두 묶음이고, 그 단언은 그대로 둔 채 주석만 고쳤다.
- 플래그 이름이 새로 생긴 것이라 승인 대상이면 알려 달라. 제품 화면 문구는 없다.

## 4. 대화 확인: 4지선다 → 술어 둘

- **바꾼 것**: `rc_reply_*` (confirm / object / neither / unsure) 를 없앴다. 대신 기록마다 예/아니오 세 문항을 묻는다. 각 문항이 그 기록을 따옴표로 인용한다.
  - `rc_stated`: 직전 답변이 그 기록을 말했나
  - `rc_confirms`: 사용자가 확인하나
  - `rc_rejects`: 사용자가 거부하거나 정정하나
- **조합 (코드, `confirmationAction`)**:
  - stated 예, confirms 예, rejects 아니오 → 승격
  - rejects 예, confirms 아니오 → 철회
  - 그 밖 (둘 다 아니오, 둘 다 예, 하나라도 미결정, 말한 적 없는 기록에 대한 확인) → 대기 유지. 침묵으로 승격하는 경로는 없다.
- **요청 축소**: 6k 안에 넣으려고 규칙을 줄이고, 시계 줄(시간 판단이 없음)과 별도 메모 목록(문항이 인용함)을 뺐다. 의미가 바뀌는 삭제는 없다고 판단했다. 실측으로 확인할 부분이다.
