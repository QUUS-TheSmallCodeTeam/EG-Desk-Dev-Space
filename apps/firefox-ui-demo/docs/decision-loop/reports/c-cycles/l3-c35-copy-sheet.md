# N1 승인표 — 루프가 추가한 사용자 노출 문구 77개 (한 번에 그룹별로 답하기)

작성: L3 (사이클 35). 근거: `l3-c31-appendix-copy-audit.md`와 `l3-c31-copy-audit-full.tsv`(3,380개 중 루프에서 새로 생긴 77개). 이 표는 문구를 **새로 만들지 않는다**. 고쳐 쓰기는 모두 "제안"이라고 표시했고, 정하는 것은 소유자다.

| **B** [보기 추천] | 숨겨진 기능의 DM 화면 | 41줄 (같은 문구를 빼면 28개) | **전부 없앰** (기능과 함께, U4) |

## 1. 기준 (먼저 정하고, 그다음 적용했습니다)
1. **사람에게 보이는 글은 모델이 쓴 글이거나 없음**이 기본입니다 (P2 결정 (나)의 원칙). 모델이 쓸 수 있거나 글 없이 되는 길이 있으면 **없앰**을 권고합니다.
2. 코드만 아는 사실(개수, 코드가 한 동작의 결과, 무엇이 전송됐는지)을 말하는 **짧은 라벨·결과 문장**은 모델이 쓸 수 없으므로 승인 대상입니다. 이름은 승인 전 도입 금지(명명 규칙).
3. 사람이 잃을 수 있는 것(전송 여부, 비용, 키, 되돌림)을 알리는 **안전·공개 문장**은 승인을 우선합니다. 결정 모델이나 네트워크가 실패했을 때도 나와야 해서 모델이 쓸 수 없는 경우가 많습니다.
4. **기능 자체가 결정 대기**인 문구는 기능과 함께 정합니다(문구만 따로 승인하지 않습니다).
5. 사람에게 표시되지 않는 문자열(내부 예외, 코드 조각)은 대상에서 뺍니다.
6. 고쳐 쓰기는 "제안"이며, 소유자가 정하기 전에는 코드에 넣지 않습니다.

## 2. 먼저 바로잡을 것: "기본으로 보이는 6개"는 정확한 말이 아니었습니다
c31 부록의 "채팅에 기본으로 보임"은 "채팅 안에 나옴"의 뜻이었습니다. 실제로 **지금 기능을 켜지 않아도 보이는 것은 A6 하나뿐**입니다. A1, A2, A3은 기억(turn memory) 기능이 켜져 있을 때, A4는 대화 흐름 기능(`EGDESK_CONVERSATION_FLOW`, 기본 꺼짐)이 켜졌을 때, A5는 작업 기억 게이트(`EGDESK_WORKING_MEMORY`, 기본 꺼짐)가 켜졌을 때만 나옵니다. 아래 표의 "켜짐 조건" 열을 보세요. 이 77개는 모두 아직 승인 전이라는 점은 같습니다.

감사 이후 확인: 감사 기준 커밋(`6c4a861`)부터 지금의 int/c14까지, 채팅 런타임과 화면(overlay) 코드에 **새로 추가된 한글 표시 문구는 없습니다**(추가된 한글은 실제 엔진 시험 스크립트, 계획 고정 데이터, 정규식 어휘뿐).
