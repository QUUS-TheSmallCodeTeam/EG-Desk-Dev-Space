## 2. warm-up 프로브를 점별로 (Main 이 다른 전송 사이에 돌릴 수 있게)

**(a) 공용 마지막 전송 stamp** (`helper/egdesk-decision-send-stamp.mjs`)
- 경로: `EGDESK_DECISION_SEND_STAMP` (절대경로) 가 있으면 그것, 없으면 `<HOME>/.egdesk-decision-last-send.json`. Main 이 모든 러너를 `HOME=$L/evidence/int-c1/home` 으로 돌리면 한 파일이 된다.
- 소유자 전용 0600, 임시 파일 + rename 으로 원자적으로 쓰고, 심볼릭 링크는 거부한다. 내용은 시각, 러너 이름, pid 뿐이다 (`startedAt`, `endedAt`, `runner`, `pid`). 키, 본문, 답은 쓰지 않는다.
- 요청이 나가기 직전에 시작 stamp 를 쓰고, 응답이나 오류가 돌아오면 끝 stamp 를 쓴다. **시작 stamp 를 못 쓰면 그 요청은 나가지 않는다** (`SendStampError`, 결과에 `send_stamp_unwritable`). 끝 stamp 쓰기가 실패하면 더 이른 시작 stamp 가 남으므로 유휴 시간이 짧게 읽히는 쪽으로만 틀린다.
- stamp 를 쓰는 러너: 일반 러너 `decision-real-measure` (플랜 대부분이 이 경로), all-on, multiuser, browser-live, memory-live, memory-real, 그리고 점 러너. 정적 테스트가 "`--send` 를 읽는 스크립트는 stamp 모듈을 쓰거나 stamp 하는 러너에 위임해야 한다" 를 확인한다. 새 전송 스크립트가 stamp 를 빼먹으면 게이트가 실패한다.
- [한계] Main 의 임시 전송 스크립트 (`evidence/main-real/*-send.mjs` 같은 것) 와, 이 커밋보다 먼저 보낸 전송은 stamp 를 남기지 않았다. 그래서 그런 전송 뒤에는 `--stamp-now` 를 한 번 해 줘야 한다. 00:50 KST 전송은 `--stamp-now --at 2026-11-25T00:50:00+09:00` 로 기록할 수 있다 (미래 시각, 그리고 디스크의 stamp 보다 이른 시각은 거부).

**(b) 점 러너** `scripts/egdesk-turn-context-warmup-run.mjs --point A1|B1|C1|A2|B2|C2`
- 먼저 stamp 를 읽어 **10분 미만이면 거부**한다. stamp 가 없어도 거부한다 (유휴 시간을 알 수 없다). 이미 결과 파일에 있는 점도 거부한다. 거부 메시지가 몇 초 지났는지와 언제 가능한지를 말한다.
- `--send` 없이 부르면 dry run: 이 점이 지금 돌 수 있는지만 말하고 아무것도 보내지 않는다.
- `--send` 면 점의 플랜을 일반 러너의 `runPlan` (제품 transport, 정확한 바이트, 재시도 없음) 으로 보낸다. 첫 바이트가 나가기 직전에 stamp 를 한 번 더 읽어 10분 규칙을 다시 확인한다.
- 점이 끝나면 stamp 가 갱신되므로 다음 점은 다시 10분을 기다려야 한다.
- 결과는 한 파일에 점마다 하나씩 덧붙인다 (`<HOME>/turn-context-warmup-results.json`, `--results F` 로 바꿈, 0600, 원자적 재작성). 점마다 시각, 직전 유휴 초, 직전 전송 러너, 요청 결과(경과/서버/소켓 재사용/연결 단계), 사용량이 들어간다. 키는 없다.
- **끼어든 전송 감지:** 점 도중에 다른 러너가 stamp 를 쓰면 그 점에 `interleaved: true` 를 남기고 경고한다. 점의 요청 전과 후에 읽고, 요청이 끝날 때 디스크의 stamp 가 자기 것이 아닌지도 본다. 한계: 다른 러너의 전송이 점 자신의 시작 stamp 로 덮여서 위 어느 읽기에도 안 걸리면 못 본다.
- 등록한 순서는 A1 B1 C1 A2 B2 C2 다. 순서를 어겨도 돌지만 `note` 가 알려 준다.

**(c) `--status`**: 끝난 점과 시각, 남은 점, 마지막 전송 (시각과 러너), 다음 점이 언제부터 가능한지 (`nextMayRunAt`) 와 지금 되는지 (`nextAllowedNow`), 안 되면 이유를 JSON 으로 출력한다. `--analyze` 는 등록한 판독 (`analyzeWarmup`) 을 지금까지의 점으로 낸다 (점이 모자라면 `incomplete`). `--stamp-now [--at ISO]` 는 stamp 만 쓰고 아무것도 보내지 않는다.
