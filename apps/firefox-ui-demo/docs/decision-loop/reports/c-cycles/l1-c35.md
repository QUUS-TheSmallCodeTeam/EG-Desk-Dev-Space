## 확인 안 됨 / 한계

1. 합성 DOM과 소스 수준 검증이다. 1, 2, 6, 7, 8은 실제 창(레이아웃, 점 위치, 팝업, 카메라, 창 재시작)에서 봐야 한다. 6번의 근본 원인(리스너 등록 시점 때문에 로드 이벤트가 팝업에 안 닿는다는 가설)은 코드와 증상으로 추정한 것이다.
2. 1번은 새로 놓이는 카드에만 적용된다. 이미 독 밑에 있는 카드를 위로 옮기지는 않는다.
3. 7번은 로그인 터미널에만 연결했다 (설정이 아닌 카드에서 열리는 터미널/브라우저의 카메라 규칙은 기존 그대로).
4. 8번의 hold는 10분 (기존 값). 그 안에 창이 다시 떠서 터미널 카드가 같은 세션으로 재진입해야 한다 (재진입을 하는 쪽은 기존 경로이며 파이프 세션으로 실제 확인하지 못했다).
5. 점 위치는 독의 세로 중앙 띠로 고정했다. 왼쪽 아래의 줌 컨트롤과 겹칠 수 있는지는 확인하지 못했다 (점은 독 왼쪽 16 px 밖에서 시작해 왼쪽으로 쌓인다).
