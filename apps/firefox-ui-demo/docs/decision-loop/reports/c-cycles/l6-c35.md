## 0. 준비 기준 (먼저)
1. **켜도 됨 (A)**: 해당 경로의 실제 엔진 기록에서 안전·정답 기대가 통과했고, 사람에게 보이는 새 문구·요소가 없으며, 알려진 결함이 없다.
2. **결정 후 켜짐 (B)**: 위 증거는 있으나 새 문구·요소·정책 판단이 하나 남아 있다.
3. **측정 필요 (C)**: 판단 층(결정 모델)은 재생이나 합성으로 통과했으나 실제 엔진에서 핵심 장면이 아직 관측되지 않았다.
4. **못 켬 (D)**: 알려진 결함이 있거나 실제 엔진 기록이 실패.
5. 같은 입력의 반복은 증거로 세지 않는다(c23). 표본이 3~16개이므로 "있었다/없었다"로 읽는다.
6. 초는 실제 기록의 서브턴 시간. 비용은 결정 모델 입력 토큰.
7. 모든 새 문구·요소는 제안이며 '승인 필요'로 표시한다.
