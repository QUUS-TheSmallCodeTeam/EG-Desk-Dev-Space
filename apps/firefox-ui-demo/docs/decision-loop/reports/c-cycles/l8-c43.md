## 2. 해결기 설계 판정
1. **"했어" 0.01, "다시 해줘" 0.68, "그만해" 0.84, "응 실행해" 브라우저 0.94의 원인은 제 쪽**: 브라우저 항목의 요약이 목표와 상태만 말하고 **사람에게 무엇을 물었는지**가 없었습니다. 해결기는 이 요약만 읽고 판단하므로 "했어"는 지시 대상이 없고("로그인했어"는 0.96), 모호한 "응 실행해"는 "계속하라"로도 읽혔습니다(0.94). 수정(c43, 제 제공자 안): 요약에 `Asked of the person: "<엔진이 한 말, 110자>"`를 추가(코드 생성, 300자 이내, 페이지 텍스트 없음; 같은 문장이 옵션 요청에 이미 인용되던 것). L1 변경 불필요.
2. **ask_page는 해결기를 거치면 닿지 않음(설계상 그렇다고 인정)**: 해결기의 참조 정의("답, 수락, 거절, 계속, 중단, 확인")가 항목에 대한 질문을 포함하지 않아 "그 페이지에 뭐 있어?"가 0.00. L1과 합의(DM): 페이지 질문은 일반 턴으로 가고, 엔진은 브라우저 도구로 페이지를 직접 읽을 수 있으며, L1의 컨텍스트 블록은 항목을 "still open"으로 계속 알려 줍니다. `ask_page` 옵션은 "로그인했어, 지금 화면 뭐야" 같은 복합 메시지에서만 도달 가능한 보조 경로로 둡니다. 해결기 변경 없음.
