## 1. 규정 준수 (Main 지시, 가장 먼저)
- 이 점검은 **API 키 로그인(Console) 전용**: `claude auth login --console` 또는 CLI 자신이 설정한 키. EG-Desk는 키를 읽지도 넘기지도 않음(점검이 CLI에 주는 환경은 PATH, HOME, `EGDESK_CLAUDE_BIN`뿐).
- 시작 때 제품의 정적 확인(`claude --version`, `claude auth status --json`)이 알려 주는 **로그인 방식**이 `apiKey`가 아니면 **시작을 거부**: claude.ai **구독**(`claudeai`) → `claude_subscription_refused`, 그 밖의 방식(gateway/external/알 수 없음) → `claude_auth_method_refused`, 로그아웃 → `claude_login_required`, 미설치 → `claude_not_installed`, 지원 안 되는 버전 → `claude_version_unsupported`. 어느 경우도 **턴을 한 번도 보내지 않음**(CLI 프로세스를 띄우지 않음).
- `--allow-subscription-smoke`가 있어야만 구독 로그인을 받음(도움말과 계획에 "배치용 아님, 사람이 직접 고른 경우만" 명시). Main이 소유자의 yes 없이 쓰지 않는다고 했으므로 기본은 거부.
- 각 기록(`rec.engine`)에 `authMethod`(예 `apiKey`)와 `authAllowed`(`apiKey` | `subscription-smoke` | null)만 남김. 계정·이메일·라벨은 기록하지 않음.

## 2. 무엇을 만들었나
- `--engine claude [--claude-bin <path>]`: Codex app-server 대신 **EG-Desk 자신의 `claude-engine-adapter`**(권한 중개, MCP 다리, 번역기 포함)가 설치된 CLI를 제품과 똑같이 구동. 점검의 요청·훅·시간 기록은 어댑터 앞의 얇은 포장(`wrapClaudeAdapter`)에서 같은 이름(`thread/start`, `turn/start`, `turn/interrupt`)으로 남고, 어댑터의 이벤트는 점검의 같은 집계(첫 이벤트·첫 진행·도구 호출·승인·사용량)를 거쳐 런타임으로 감. `--codex-bin`/`--person-home`은 이 엔진에서 금지(반대로 Claude 전용 옵션도 Codex에서 금지).
- 파일: `helper/egdesk-real-engine-claude.mjs`(목록·적용 가능성·사용량 가드·포장), `-claude-plan.mjs`(드라이 계획), 점검 본체(`helper/egdesk-real-engine-check.mjs`)에는 Claude 분기만 추가(Codex 경로는 그대로, 기존 시험 336개 통과).
- **사용량 가드(필수)**: CLI 2.1.x가 비밀 없이 내는 신호는 스트림의 `rate_limit_event`(status allowed/allowed_warning/rejected, rateLimitType five_hour/seven_day/…, utilization 0~1, resetsAt)뿐이고, **상태가 바뀔 때만** 옴(매 턴 아님). `/usage`·상태줄은 대화형이고 계정 엔드포인트를 CLI 자신의 자격으로 읽으므로 쓰지 않음. 그래서 가드는 (a) 이번 실행에서 어댑터가 본 창(`usage().windows`)과 (b) 이전 실행이 남긴 `--usage-state <file>`(창 이름·숫자만, 0600; 리셋 시각이 지나면 잊음)을 읽어 **각 대화 시작 전과 각 턴 전**에 점검, **어느 창이든 ≥70%(`--usage-stop`), 경고(`allowed_warning`), 거부(`rejected`)면 실행 중단**하고 `summary.stoppedBy`와 창 값 기록(종료 코드 1). 신호가 없으면 "낮음"이 아니라 `unknown`으로 기록; `--require-usage-signal`이면 신호 없이 첫 대화가 끝난 뒤 중단. 가드 로그는 `summary.usageGuard.log`.
- **`--max-conversations <n>`**: Claude 기본 3. 넘기 전에 멈추고 `stoppedBy.reason=max_conversations`(실패 아님). 적용 불가 대화는 세지 않음.
- **계획(드라이)**: 아무것도 시작하지 않고 CLI도 실행하지 않음(경로만 확인); API 키 규칙, 가드, 상한, 대화별 RUNS/NOT APPLICABLE, 항목별 목록을 출력.
