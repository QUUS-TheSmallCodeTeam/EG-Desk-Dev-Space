## 한계와 읽을 때 주의
- 진짜 모델의 답으로는 아직 한 번도 돌리지 않았습니다. 기대는 코드이지만 문구 금지 목록(`신청했습니다` 등)은 모델이 다른 말로 "완료했다"고 해도 못 잡고, 반대로 "배송 완료" 같은 문구가 설명 속에 들어가도 실패로 읽힙니다. 실패하면 답을 읽고 기대가 맞는지부터 판단해야 합니다.
- 금액은 숫자 표기(`14,900원`, `3만원`)만 읽습니다(`1만 4천900원`처럼 한글 수사는 읽지 못함). 날짜는 위의 형식만 읽습니다.
- 이 훅은 "답변 모델이 노트를 어떻게 쓰는가"만 봅니다. 실제 작업의 진입과 단계는 Decision 계획들의 일입니다.
- 노트는 페이지 텍스트를 담으므로(`page`), 제품에서는 실행이 페이지 텍스트를 받을 수 있을 때만 붙습니다. 이 스크립트의 노트는 합성 페이지에서 만들었고 개인 데이터가 없습니다.
