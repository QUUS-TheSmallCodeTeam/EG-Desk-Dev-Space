- **555 `the mouse path is unchanged`** (test:~16120). 의도: 방을 마우스로 열 때도 같은 방 목록 복원(`choice.selectListRoom`) 후 `selectThread(..., { openConversation: true })`. 근거: 커밋 "same-room list restore", 짝 경로 `openRoomFromKeyboard` (surface:12964)가 동일. 대체: 마우스 정규식을 새 리터럴로 고정 + 키보드 하네스에 `choice` 스파이를 주입해 `[['selectListRoom','room-a'], ['room-a', {openConversation:true}]]` 호출 순서를 정확히 검증 (이전엔 selectThread 한 번만 검증했으므로 오히려 강해짐).
- **556 render 시작부** 정규식: 의도: 조합(IME) 중에는 render를 미루는 가드 유지. 근거: 484ba33이 `choice.sync()`를 가드 앞에 추가 (surface:13071). 대체: `choice.sync();` 다음에 동일한 `compositionInProgress` 가드 전문을 그대로 요구.
- **627 footer 배선** 정규식: 의도: CTX 제안 영역이 입력행 위에 있음. 근거: 484ba33이 그 사이에 `choice.panel` 삽입. 대체: 순서 `buildContextSuggestions -> boardDestination -> choice.panel -> input-row`를 요구.
