### P1 (재현, 수정): 배치 추천 실패가 화면에서는 모두 "사용할 제안이 없습니다"
- 재현(패치 전, `journey-before.tap`): 지출 한도 429 뒤 패널 상태줄이 `사용할 제안이 없습니다. 수동으로 구성을 고르세요.`(모델이 답을 못 낸 경우와 구분 불가). 같은 사유를 DM 보기 추천(`eg-desk-surface.uc.js` outcomes 표 ~12719-12735)은 이름을 대고, 시간 초과는 '요청은 이미 보냈으므로 비용이 청구될 수 있고'까지 알려준다. L3가 보낸 뒤 취소/시간 초과를 예산에 추정으로 세는데 배치 경로는 사용자에게 아무 말도 하지 않았다. 4b(로컬 월 한도, 준비 단계 `disabled/budget-exceeded`)도 같은 일반 문구('외부 제안을 사용할 수 없습니다…')로 가는 코드 경로다(4b의 패치 전 실행 관찰은 하지 않았고 코드 읽기: `EGDeskJointPresentation.sys.mjs` prepare 검증 분기).
- 수정: `egdesk-board-presentation-http.mjs`: `run()`이 실패를 닫힌 사유 단어만 담아 응답(`{status:'manual', reason}`: no_credit, rate_limited, timeout(보냄)/timeout_unsent, budget_exceeded, spend_limit_reached, invalid_key, unreachable, server_error, model_unavailable, bad_response). 공급자 문구·세부는 여전히 반환하지 않음. `EGDeskJointPresentation.sys.mjs`: `FAILURE_NOTES` 표(DM 표와 같은 문장)로 상태줄 표시, 준비 단계 `budget-exceeded`도 같은 문장. 그 외 응답은 기존 '사용할 제안이 없습니다…' 유지. 보안 가드(재확인, 티켓 소모, 중단)는 변경 없음.
