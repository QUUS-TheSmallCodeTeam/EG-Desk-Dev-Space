## 2. 문제 (관찰값, file:line은 패치 전 int/c1 기준)

P1. topic 배치가 폐기되면 사용자가 이름으로 지목한 Board 항목도 조용히 사라짐, 줄도 없음.
 - 관찰: 발화 "지금 배포 체크리스트 서버가 켜져 있어." topic on + 경로 미확신 → `status=skipped, reason=evidence_unavailable, selected=[]` (기대: 이름이 정확히 들어간 `board:1` 은 `mentioned`).
 - 원인: `chosen = scored.filter(row => row.reason && (!discardJudgments || independentFile(row)))` egdesk-context-setup.mjs:303, `fileItems = items.filter(independentFile)` :317. `independentFile` 은 memory-lookup/selection 파일만 허용. `mentioned`/`mandatory` 는 모델 판정이 아니라 로컬 문자열 일치/앱 고정인데 같이 버려짐. 줄 없음은 `noteDecisionContext` 의 `result.status === 'skipped' || result.privateTopicBatch` 조기 반환 codex-chat-runtime.mjs:4400.
P2. 사용자가 왜 인용이 붙었는지/안 붙었는지 볼 수 없음.
 - 관찰: speech on 에서 라벨 3축 전부 보류(0/3)여도 줄은 "컨텍스트 세팅 · 붙일 자료 없음"/"자료 1개". 실제로는 규칙+시계+빈 라벨 `[]` 블록이 붙음(packet 비어있지 않음). recall 판정(0.16=no, 0.5=yes)은 receipt에 없음(`receipt.unknown` 은 `scored` 행만, `rel_recall` 은 yes 일 때만 scored에 들어감 :300-302). 항목 상한/예산/읽기 실패로 빠진 행의 기록 없음(`assemble` 이 `continue`/`break`, `.slice(0,maxItems)` :303-305).
 - 줄 제목 생성 egdesk-context-setup.mjs:524.
P3. 선택 행이 0.45인데 confidence 0.93 주장으로 라벨 채택(inconsistent 행: source=unspecified 채택).
 - 위치: `pick()` 은 주장 confidence≥0.85 와 행 기반 margin 만 검사 egdesk-speech-grounding.mjs:227. 기존 테스트 `confidence and actual winner margin are independent, inclusive checks`(speech-grounding.test.mjs:111-113)가 "confidence 0.85 주장 + 선택 행 0.60" 을 채택으로 못 박고 있음.
 - 조치: 패치 시도 후 이 테스트와 충돌(의도가 "두 검사는 독립"). 단언을 바꾸면 의도 약화이므로 **되돌림**. 미패치, 미해결 질문으로 남김(7장). 실제 API에서는 confidence=선택 확률일 것으로 추정되지만 batch 경로에서 client가 검증하지 않음(egdesk-decision-client.mjs:161-163).
P4. (관찰만) near-tie recall 이 0.5 정확히에서 과거 발언 인용을 붙임: 일반 `relevant` 임계값 0.5 를 그대로 씀(:300-301). 라벨은 0.85+margin 0.2 인데 recall 은 무마진. 인용은 `verification: utterance-only` 이고 한도 5200자라 피해는 토큰/주의 분산. 사용자 동의 범위 안이며 사실 주장이 아니므로 미패치.
P5. (관찰만) timeout/fallback 에서는 그 발화가 speech 기록에 아예 남지 않음(`status==='ready'` 일 때만 record, codex-chat-runtime.mjs:2580-2584). 실제로는 timeout 시 AbortController가 `speech.allowed()` 를 false 로 만들어 기록 자체가 막힘. 예산/abort 영역은 L5 소유라 미패치.

미확신 분류가 저장에 영향? 아님: low/neartie/abstain/invalid 모두 라벨 0건 저장(`stored=[0]` 길이 0). 과거 인용 누출(동의 off)? 0건. 시점 라벨이 앵커 없이 단정? 아님: 라벨은 시계/비앵커 문자열만, 날짜 값 생성 없음.

## 6. 철학 점검

"보기가 모자라면 억지로 분류하지 않는다" / "Decision Model의 동의·높은 점수는 사실 증명이나 쓰기 권한이 아니다": 실측 0.16 분류는 어느 경로에서도 저장·부착되지 않았음(라벨 0건, `form=unknown`). 패치는 이 원칙을 건드리지 않고, 보류 사실만 보이게 했다. 반대로 "이름으로 정확히 지목한 항목"은 점수가 아니라 사용자가 한 말이므로 모델 배치가 폐기돼도 모델의 침묵이 사용자 지목을 지우지 않는다. 시간은 앵커만 기록하고 달력 산술은 하지 않는다(:101-106).
