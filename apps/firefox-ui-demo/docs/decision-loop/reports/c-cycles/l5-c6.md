## 2. 같은 데이터 공유 권한 (D2)
### 2.1 찾은 기존 권한 구조 (모델이 받을 수 있는 것을 정하는 것들)
- **Agent 도구 상한**(`toolCeiling` browser/files/terminal/network/mcp; `codex-chat-tool-ceiling.mjs`, `run.toolCeiling`)
- **선택한 Browser Card 부여**(`run.browserBinding.cards[].permission`, 선택 source의 `browserToolSelection`)
- **캔버스 카드별 `maySend`**(호스트가 계산하는 "이 카드가 모델로 갈 수 있는가"; `egdesk-briefing-flow.mjs`가 이미 이것으로 후보를 거름)
- **메모리 범위**(`allowsPage(page, scope)`: 페이지 자체 가드 + 답변 모델이 읽을 수 있는 범위)
- **DM별 발언·주제 재사용 동의**(`speechConsentState`/`topicConsentState`, 답변 모델에게 과거 발언을 주는 바로 그 동의)
- Board: 소유자의 요청별 발췌 선택(아래 "남은 항목")

### 2.2 공통 도우미 `helper/egdesk-decision-egress.mjs`
- Decision 전용 동의·스위치·허용 목록이 **없다.** 입력은 위 모델 권한 구조뿐(`modelDataPermissions`: terminal / browser / canvas / run / memory / speech / topic). 목록에 없는 kind, 닫힌 클래스는 거부.
- `guardClient(client, kinds)`: 허용되지 않은 kind면 키 조회·요청 **이전에** `DecisionError('evidence_unavailable')`로 거부(요청 0). 모든 기능은 이미 DecisionError를 폴백으로 처리한다.
- `filterEvidence`(draft-check 카탈로그를 kind로 거름), `memoryScope`(기존 범위에 "그리고 memory 클래스"를 더해 **좁히기만**).
- `EGRESS_SITES` 레지스트리 + 코드 스캔 테스트: Decision 요청을 보내는 파일이 목록에 없으면 게이트가 실패(새 호출 지점은 반드시 등록).

### 2.4 남은 항목 (정직하게)
- **Board 답변 발췌(`egdesk-board-agent-context.mjs`)는 아직 통일되지 않았다.** 지금은 소유자가 요청마다 켜는 "관련성 판단을 위해 별도 OpenAI Decisions API…" 체크박스(`decisionEgress`)가 유일한 근거다. D2에 따르면 이 별도 체크박스는 없어지고, 발췌는 초안 모델이 받을 수 있는 경우(`draft` 모드)에만 Decisions로 가야 한다(`extract` 모드는 어떤 모델도 발췌를 받지 않으므로 Decisions도 받지 않음). 이는 Board 패널 UI(`EGDeskBoardAgentAsk.sys.mjs`의 체크박스·확인 문구)와 Board 계열 테스트 다수의 변경이 필요해 이번에 건드리지 않았다. 레지스트리에 "NOT yet unified"로 표시. 제안 문구/흐름은 승인 필요.
- 런타임 통합 지점의 단위가 아닌 **통합 시험**(예: 반사 `reflexScope`의 gate가 run 도구 상한으로 닫힘)은 별도로 추가하지 못했다. 게이트 동작 자체는 위 per-kind 시험으로, 기존 provider/runtime 시험(504건)은 통과로 확인.
- `speech/topic`은 이미 동의 가드가 코드에 있어 새로 배선하지 않고 게이트 수준에서 같은 동의에 묶는 시험만 추가했다.

## 3. 시험 (`helper/egdesk-decision-egress.test.mjs` 외)
각 kind: 허용 → 요청이 나가고 데이터를 싣는다 / 불허 → 그 데이터를 싣는 요청 0건이고 기능은 기존대로 폴백.
- 권한 파생(도구 상한·Card 부여·maySend 등만 입력), 알 수 없는 kind·닫힌 클래스 거부, Decision 전용으로 열 수 있는 입력 없음
- 가드 client: 요청 전 거부, 닫힌 코드
- terminal_output / terminal_command / draft_text(kind 필터: terminal 항목은 제외, source 항목은 전송) / page_text(도구 상한 none과 Card 부여 없음 두 경우) / browser_task_record+memory_page / memory_page(범위 밖 페이지 본문이 요청에 없음) / speech·topic 동의 / 레지스트리 스캔
- 브리핑: `scripts/egdesk-briefing-flow.test.mjs`에 canvas_text(불허 → 요청 0, 허용 → 판정 요청)
- 터미널 시험의 `consent` 케이스는 "도구 상한 terminal=none"으로 교체(요청 0, 폴백)
