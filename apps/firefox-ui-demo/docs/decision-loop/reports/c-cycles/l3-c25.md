## 4. 증거 병합이 실제 증거를 지울 수 있는가

- **id로 확인할 수 없다.** 제목 항목은 컨텍스트 선택(id `ontology:…`)에서, 페이지 항목은 기억(id `mem…`)에서 온다. 그래서 병합은 텍스트 비교로만 할 수 있다.
- **v6 여정에서 지운 것은 4건이었고, 모두 맨 제목이다.** 각각 남은 페이지 텍스트의 앞부분으로 그대로 들어 있다.
  - s1: `a-v1`("A사 견적서 v1 발송"), `a-decision`("A사 건 결정 메모")
  - s3b: `pg-design`("PostgreSQL 전환 설계"), `pg-plan`("PostgreSQL 마이그레이션 배포 계획")
- **지우지 않은 경우:** `a-meeting`(status `reported_by_other`)은 메모리의 같은 페이지(`unknown`)와 status가 달라서 남았다.
- **이론상 지울 수 있다.** 같은 시간·status를 가진 짧은 기록이 낱말 경계에서 다른 기록의 앞부분과 같으면 지워진다. 예: "배포 완료"와 "배포 완료 여부는 미확인". 이 경우 짧은 쪽이 따로 말하는 내용이 사라진다. 이 여정에는 없었지만 규칙이 막지 않는다.
- 단독 효과는 측정하지 않았다. 그래서 되돌렸다.
