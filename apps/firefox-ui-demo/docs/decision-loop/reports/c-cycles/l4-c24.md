## 1. 코드가 만드는 자료 (원장 + 레인 보고서, 읽기 전용)
- `helper/egdesk-briefing-ledger-materials.mjs`(순수 함수): `parseLedger`, `parseReport`, `buildLoopPages`, `mergedLaneCycles`, `statedStatus`, `maskSecrets`.
- `scripts/egdesk-briefing-loop-materials.mjs`: `$L/LEDGER.md`와 `$L/reports/l*-c*.md`를 읽고, 페이지와 요약을 저장소 밖에 0600으로 씁니다. 저장소 안으로 쓰려 하면 거부합니다.
- **날짜**는 원장 줄 `- MM-DD HH:MM …`에 적힌 것만 씁니다.
  - 그 줄들에는 **연도가 없습니다.** 그래서 연도는 호출자가 근거와 함께 선언했을 때만 붙입니다(`--year 2026 --year-basis "…세션 디렉터리 2026-11-15…"`, 요약에 기록). 선언이 없으면 모든 날짜가 null입니다(테스트).
  - 시각(HH:MM)은 제목과 발췌에 그대로 남습니다.
  - 있을 수 없는 날짜(02-30 등)는 null입니다.
- **상태**는 글에 적힌 말로만 정합니다.
  - 원장 줄: 병합/merged → done, 배정/착수 → plan, 수신 → reported_by_other, 그 밖은 unknown.
  - 보고서 페이지: 원장이 그 레인-사이클의 **병합을 커밋 id와 함께** 적었으면 done이고, 날짜도 그 줄의 날짜입니다. 아니면 reported_by_other이고, 날짜는 보고서가 직접 적은 것이 있을 때만 씁니다.
  - 예: "L1 c12(49be194)는 충돌 2파일 → 재병합"은 L1 c12의 병합이 아닙니다(테스트).
- **링크**는 글이 이름을 댄 것만 만듭니다: 보고서 → 같은 레인의 이전 사이클(follows_from), 원장 줄 → 그 줄이 이름을 댄 레인-사이클 보고서(refers_to), 같은 레인-사이클을 이름 댄 원장 줄끼리(same_task).
- **비밀값은 늘 가립니다**: sk-/gh/xox 키, JWT, Bearer, `token=` 같은 자격 증명, 이메일, 홈 경로. 커밋 id와 레인/에이전트 id는 식별자라 남깁니다.
- **실제 스냅숏**: 263페이지(보고서 134, 원장 줄 129). 날짜 있음 166, 없음 97.
  - 원장 상태: unknown 62 / plan 28 / reported 12 / done 27.
  - 보고서 상태: done 37 / reported 97.
  - 스냅숏 식별: `pages.json` sha256 `faace5f4…`. 원장은 182줄 시점이며, 지금은 184줄로 자라 있습니다.
- 출력은 L7 메모리 행과 같은 모양입니다. 스켈레톤의 `normalizeMaterials`가 날짜, 상태, 링크를 그대로 받는 것을 테스트로 확인했습니다.

## 4. 이것이 보여줄 수 있는 것 / 없는 것
**보여줄 수 있는 것**
- 합성 A사 자료가 아닌 **실제 날짜, 상태, 용어**로 된 자료에서 다음 판정이 성립하는지:
  - 보드 대 말풍선 판정(combines + 관련 자료 수 규칙).
  - 사실 단위 커버리지.
  - 다른 사이클이나 사건을 버전으로 오인하는지(same).
  - 관련성(about).
- 한 문장 사실 질문이 실제 자료에서도 말풍선이 되는지.

**보여줄 수 없는 것**
- **기억 루프의 선택**: 자료는 코드 규칙으로 골랐고, 제품의 L7 기억 루프가 고르는 것과는 다릅니다.
- **주관식 모델의 실제 답과 채움**: 답은 내가 자료에서 썼고, 채움은 복사입니다. 즉 "채움이 충실할 때" 판정이 맞는지만 봅니다.
- **fit/order의 실제 결과**: 커버리지 body가 인용하는 보드는 모의 fit/order로 만든 오프라인 보드입니다. 실제 fit 답이 다르면 제품에서는 다른 보드가 됩니다. 각 단계를 독립적으로 재는 것이며, L2의 방식과 같습니다.
- **실제 화면과 설치 앱**: 둘 다 확인하지 않았습니다.
- **연도**: 원장 줄에 연도가 없어 2026은 선언값입니다(근거는 기록됨). 판정은 같은 날 사건들의 순서가 시각 글자에 기대게 됩니다.
