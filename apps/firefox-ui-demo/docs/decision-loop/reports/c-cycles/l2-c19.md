### 2.2 nudge 단계(s4n)가 보여 준 것

- **받아들임**: 작성창이 보낸 것과 같은 방식(`inRunMessageTo`)으로 run이 받아들였고, 사람의 말로 한 번 보였습니다.

**이 단계가 증명하지 못하는 것**:
- 진행 답의 **문장은 측정 스크립트가 쓴 것**입니다(`waitNote`가 작성기 프롬프트에 "The person just wrote, while you work"와 "a command is still running"이 있으면 정해진 문장을 돌려줌). 그래서 `s4n.one-reply`, `s4n.reply-says-running`, `s4n.no-duplicate-wait`는 **실제 작성 모델의 글이 아니라 이 문장**을 판정합니다. 증명된 것은 L3 쪽이 올바른 사실을 담은 작성 요청을 만든다는 것과, 실제 Decision 모델이 이 메시지를 "상태 질문"으로 가렸다는 것입니다.
