## 동작 (플래그 켬, 자체 도구, Decisions 켬)

3. **승인 규칙은 그대로**: 먼저 규칙 바닥(`classifyCommand`, 파괴적이거나 바닥 사유가 있으면 빠른 경로 안 탐 → 엔진), 그다음 자체 실행기의 문(승인 원장)을 그대로 통과. 승인이 필요하면(`needs_person`) 결과를 엔진에 맡김(아래).

## 새 화면 요소와 문구 제안 (승인 필요, 출고 안 함)
1. 빠른 경로 결과의 **한 줄 요약 칩**(예: 터미널 카드 아래 "성공 · 5/5" 같은 칩): 지금은 터미널 카드(종료 코드, 출력)만 보이고 글은 없음. 칩이 없으면 "끝났는데 아무 말도 없다"로 보일 수 있음(가장 큰 UX 질문).
2. **설정 토글**("명령 요청은 빠르게 처리" 같은 이름과 설명 문구): 지금은 개발자 플래그뿐. 켜면 사람의 메시지와 폴더에서 만든 고정 설명이 **결정 모델(OpenAI)로 감**(기존 결정 모델 안내에 포함할지 문구 결정 필요).

4. 승인이 필요한 명령을 빠른 경로가 만났을 때의 안내 문구는 **엔진이 지금처럼 말로 함**(새 문구 없음).
5. 후속: 빠른 경로가 고른 옵션을 사람이 바꾸는 방법(예: 터미널 카드의 "다른 명령") — 새 요소, 제안만.
