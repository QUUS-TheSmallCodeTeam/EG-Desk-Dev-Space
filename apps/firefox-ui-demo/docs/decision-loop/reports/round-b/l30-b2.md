# L30 b2: 두 번째 결과 열기, 사용할 수 없는 사이트 질문

`lane/b-endings2` / `5d19fcb8b973d27f433281ac47eea28c136e2b38` (기준 `2b3c7ce`). 변경 파일은 `apps/firefox-ui-demo/helper/egdesk-browser-reflex.mjs`, `egdesk-browser-step-candidates.test.mjs`, `egdesk-page-tools.mjs`, `egdesk-page-tools.test.mjs` (모두 같은 helper 디렉터리). `choice_requested` 문장은 수정하지 않았다.

**확인 1:** 도착판정은 새 링크를 열기 전에는 타지 않는다. 반면 결과가 열린 카드에서 새 목표의 첫 결정은 검색 필드·값 필요·링크·탭을 함께 제시했다. L30에서 추가한 `open_only`도 같은 요청에 들어간다. `needs_free_text`를 고르면 “값 필요”가 되고, `next_step`이 미결정이어도 `soleField`가 있으면 진입의 `undecidedField` → `pickFieldText`/“값 필요”로 나갈 수 있다. 검색 결과에 텍스트 필드가 딱 하나 있으면 이미 값이 있는 검색칸도 `soleField`가 된다. 실창의 개별 판단 응답은 받지 않았으므로 어느 분기였는지나 L30의 추가 질문이 확률을 바꿨는지는 단정하지 않는다.

**수정 1:** 처음부터 “두 번째 결과 열어줘”처럼 순번 결과를 여는 것만 명시한 한국어 요청이면 판단 대상은 현재 관찰한 안전 링크들과 식별 불가/막힘뿐이다. 링크 순서는 표시 순서이고, 같은 주소의 앵커는 기존처럼 합친다. 검색칸·값 필요·단독작업 재질문을 제외하고, 후보 중 어느 결과인지는 여전히 모델이 기존 확신·차이 기준으로 결정한다. 신호가 불충분하거나 서로 충돌하면 필드로 가지 않고 넘긴다. 사이트 허용, 허용 후 대상 재관찰, 실제 URL 도착 증거는 그대로다. 일반 검색·복합 요청은 기존 경로를 쓴다.

**확인 2:** `egdesk_card_press`는 사이트 허용을 받으면 재관찰 후 `egdesk_browser_navigate`를 발행한다. 이어가기 자체는 빠지지 않았다. 브라우저 서비스에서 해당 `BROWSER_OUTCOME_UNKNOWN`은 이전 물리 동작 결과가 미확인이라 카드가 잠긴 경우 *다음 이동을 발송하기 전에* 내는 코드다. 사이트 승인과 잠금은 독립적이어서 질문에는 허용해도 실제 이동은 거절된다. 당시 잠금을 건 구체적인 영수증은 미수집. 미확인 fill → 카드 읽기 → 외부 링크 직접 누르기로 같은 조건을 재현했다.

**수정 2:** 직접 누르기는 브라우저 관찰에 남은 `uncertainAction`을 버리지 않는다. 잠긴 채라면 쓸 수 없는 허용 질문을 띄우지 않고 기존 `BROWSER_OUTCOME_UNKNOWN`으로 멈춘다. 잠금을 풀거나 클릭을 반복하지 않는다. 정상 카드는 기존처럼 허용을 받은 뒤 정확한 주소·이름으로 링크를 다시 찾아 한 번 이동한다. 잠긴 카드까지 강제 이동시키는 수정은 하지 않았다.

**시험:** 집중 140/140 통과 (`$L/evidence/l30b2-focus.tap`). 결과 카드 fixture(원본은 이름만 보존)에 URL이 다른 두 나무위키 결과를 넣어, 두 번째 요청에 필드 후보가 없고 두 번째 링크에만 사이트 질문과 이동이 있음을 검증했다. 확률 미달/엉뚱한 필드 답은 아무 입력 없이 멈춘다. 별도 시험은 실제 브라우저 서비스 대역에서 영수증 미확인 후 직접 외부 링크 질문·이동이 모두 0회임을 검증한다. 정상 직접 누르기/거절 시험도 통과했다.

**Main 실창**: 병합 빌드의 Codex 새 대화에서 DuckDuckGo 카드에 `덕덕고 카드에서 장화 신은 고양이 검색해줘` → `작업 끝`과 q 확인. 화면에서 실제 두 번째 결과 제목·목적지를 확인하고 같은 대화에 `두 번째 결과 열어줘`. 검색 필드 입력이나 '값 필요' 없이 목표 링크가 선택되는지, 사이트 허용을 13초 뒤 주어도 해당 목적지 한 번만 열리고 작업 끝인지 본다. 새 대화로 거절도 대조(이동 0회). 불확실하면 실제 두 번째 링크인지 확인 없이 완료를 기대하지 말 것. 이 레인은 실제 엔진/가동 앱을 사용하지 않았다.
