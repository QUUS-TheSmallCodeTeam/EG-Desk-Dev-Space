- **수정**: navigate에 명시적 사후조건이 *없을 때만* 목적지 전체를 `{kind:'url', value:url}`로 복원한 뒤 똑같은 검증·신선도·권한·사이트 정책·actor·결과 확인 경로로 보낸다. 명시된 다른 종류는 무시하거나 성공으로 바꾸지 않는다. `visible-text`를 준 경우 모델 오류와 `browser.tool.failed`에 `invalidBy: navigation-postcondition-kind`가 남는다. 설명에 관찰 인자, URL 사후조건 예, 도착 후 텍스트 확인은 observe라는 점을 명시했다. 저장된 매니페스트에 해시된 입력 스키마는 바꾸지 않았다.
