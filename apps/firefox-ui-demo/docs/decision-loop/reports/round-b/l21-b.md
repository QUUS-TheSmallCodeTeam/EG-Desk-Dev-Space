## 수정과 시험
- 직접 진입에서만 실제 사람 메시지(요청이 바뀌었으면 마지막 변경)를 별도로 전달. 모델이 만든 goal, 기억이나 페이지 텍스트로는 클릭 예외를 얻지 못한다. Decisions가 후보를 선택하며 기존 민감 페이지·관찰 신선도·대상·카드 권한 검사를 통과해야 한다.
- 명시 클릭에는 모델 JSON에서 구성할 수 없는 내부 후조건을 사용한다(객체 정체성, 공개 도구·스키마·플래그 추가 없음). 정상 대상에 DOM click이 전달됐다는 액터 영수증을 받은 뒤 동일 카드의 **같은 문서·정확히 같은 URL**을 새로 관찰한다. 약 250ms 간격, 추가 대기는 최대 8초 또는 더 짧은 요청 예산. 새 글/요소 상태 또는 관찰한 로딩 표시가 사라져야 done. revision 증가, 클릭 영수증 또는 버튼 소멸만으로 성공 처리하지 않는다. 미확인은 재클릭하지 않는다. 외부 효과 성공을 주장하지 않는다.
- `done` 메모에 글자가 없으면 대화 모델은 현재 카드를 읽어 한 번 답한다. `cannot`과 사람이 할 단계를 구분하고 불확실한 클릭을 반복하지 않도록 안내한다. 효과 미상 버튼에 대해 task tool이 직접 누르라고 권했던 응답도 human_step으로 정정했다.
- 회귀: 가짜 카드/결정으로 `Start → 검증된 Hello World! → done` 1결정·1클릭. 실제 helper 서비스 + 가짜 액터로 `Loading... → 320ms 뒤 Hello World!`를 신선한 관찰 ID로 확인. 외부 JSON으로 후조건 복제 거부. POST·로그인·삭제·민감 상위 영역·href·동명이름·Restart 부분 일치·사람 메시지 부재는 예외를 얻지 못함.

## 소유자 확인 필요
- 기존 GET/패널 규칙을 변경하지 않고 **효과가 미리 알려지지 않은 버튼**에 다음 한 가지 권한을 추가한다: 실제 사용자 요청이 관찰한 활성 native `<button role=button>`의 전체 이름을 정규화(NFKC·대소문자·공백/구두점·일부 한국어 조사)하여 유일하게 지목하고, 페이지/버튼이 일반 동작으로 분류될 때 한 번 누를 수 있다. 철자 추정·의미 유사도·단어 중간 부분 매칭은 하지 않는다.
- 최상위 문서의 일반 DOM, form·anchor 밖, form/formaction/href 없음, 민감·비공개 표식 없음, 관련 상위 영역의 라벨도 민감·행위 어휘가 아닌 경우만 해당. 확인할 수 없는 조상·라벨 참조는 예외를 주지 않는다. 결제/권한/삭제/로그인·쓰기 제출은 사람 몫; 다른 사이트 링크는 기존 카드 사이트 허가 경로뿐. 명칭 없는 효과 미상 버튼은 계속 수동이다.
- **잔여 위험:** `<button>`의 페이지 JS 핸들러가 AJAX 쓰기·이동 같은 부수효과를 일으키는지는 DOM으로 입증하지 못한다. 사람의 지목을 그런 버튼 1회에 대한 동의로 볼지를 소유자가 승인해야 한다. 결과 변화도 인과 증명이 아니다. 타이머·광고에 의한 새 내용, 알려진 로딩 텍스트/역할이 없는 스피너, 8초 이상 대기는 오판/미확인 가능. 복합 요청에서 이름 버튼 후 필요한 추가 조작까지 완료했다는 보장은 없다.
