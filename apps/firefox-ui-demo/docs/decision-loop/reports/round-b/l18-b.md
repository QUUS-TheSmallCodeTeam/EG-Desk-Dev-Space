## 진입은 기록이 없어서 사후 복원할 수 없다

## 호출 구간 보정: 실제 기록 재생 결과

`browser.tool.{completed,unverified,failed}`의 `details.callId`가 `<activity id>.guide.reflex-N-*`일 수도, `bt_<id>.sK.reflex-N-*`일 수도 있다. 전자는 ID/prefix로, 후자는 해당 시각을 포함하는 `egdesk_browser_task` 활동이 유일할 때 그 호출에 귀속한다. 정렬 후 호출+reflex prefix별 직전 완료 시각 또는 해당 호출 시작부터 계산한다. 턴 전체에서 첫 `browser` 결정 호출을 가져오지 않는다. 시작 미상이면 완료 기록은 세고 시간을 추정하지 않는다(행렬 초 null).

| 스레드 | 호출별 ‘단계 1’ ms (전 → 후) | 저장 단계 합계 ms (전 → 후) | 실패 / 미확인 |
|---|---|---|---|
| `thread-dm-8dysu9y` | 5009, 9473, 12013, 41823 → 26, 35, 47, 32 | 11단계: 71313 → 3135 | 3 / 1 |
| `thread-dm-23ileuo` | 5415 → 26 | 7단계: 7746 → 2357 | 0 / 1 |

동일한 닫힌 사건 투영과 같은 호출 파일로 기준/수정 분석기를 각각 실행했다. 41823ms는 종전 `2297 + 39526`, 5415ms는 `1168 + 4247`이었다. 이 2개 첫 단계는 수정 후 32ms / 26ms이다. 분할 시간은 해당 구간과 겹친 browser 호출의 합집합이며 제품이 각 단계의 실제 내부 CPU/실행시간을 제공하는 것은 아니다.

## 라운드 측정 사용법

아래는 기존 측정 담당자의 일반 CLI 사용 예. 실행 중인 앱을 읽지 않는 재생은 `--from <기존 --save 닫힌 JSON>`을 같이 지정한다. 기존 `--json <파일>`의 상세 기록, `--rows`의 사람용 단계 표와 출력 형식을 유지한다. **`--row`는 stdout JSONL 한 턴 한 줄**, 진단은 stderr, 무매치는 stdout 빈 값/종료 1이다.

```sh
N=/Users/minsoocha/.aside/runtime/node/bin/node
cd "$L/wt-l18-b/apps/firefox-ui-demo"
"$N" scripts/egdesk-turn-timeline.mjs --thread thread-dm-8dysu9y --turn 1 --row --calls "$L/evidence/a1-live/calls.json"
# 저장본 재생: 특정 스레드의 최신 매칭 턴만
"$N" scripts/egdesk-turn-timeline.mjs --from "$CLOSED" --thread "$THREAD" --last 1 --row
```

`--turn N`은 정확히 하나의 `--thread`와 사용한다. N은 필터 전 스레드 내 1부터의 턴 번호다. `--thread`만 주면 해당 스레드의 여러 턴이 나올 수 있다. 케이스/반복 번호는 행을 수집하는 측정기가 붙이고, `thread,turn,requestId,engine`으로 행을 확인한다.

행 필드: `totalSec`, `firstActionSec`(저장된 첫 실패 아닌 화면 액션 **완료**, wait/site 제외, 없으면 null), `decisionSteps,decisionStepSec`, `engineSegments,engineSec`, `toolsEngineDirect,toolsEngineDelegated,toolsDecisionDirect`(도구 활동 기준 상호 배타, 위임 wrapper는 한 번), `browserFailures`(명시적 실패만, unverified 별도 상세 JSON), `humanWaitSec`(기존 허용/질문 구간 및 site 판정). `decisionStepSec`은 기록된 단계 구간 합이지 결정 API 호출 시간만의 합이 아니다. `engineSec`은 native run에서 도구·사람 기다림을 제외한 구간이다. 서로 다른 계층의 수치를 모두 더한 값이 totalSec이 아니다.
