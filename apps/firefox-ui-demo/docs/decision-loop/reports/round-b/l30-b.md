## 확인·수정

1. **언어**: 첫 턴인지, 메모가 `human_step`인지에 따라 L26 언어 지시가 빠지는 분기는 없었다. 반면 Claude가 카드 도구를 사용한 직후의 새 MCP 결과는 페이지/도구 응답만 담았다. Claude + browserBounded + 하네스에서만 도구 결과 끝에 기존 `REPLY_LANGUAGE`를 별도 모델 입력 블록으로 붙인다. 원래 도구 JSON과 사용자가 보는 답은 변형하지 않는다. 사람 단계 인계 메모가 붙은 첫 턴 → Claude 카드 읽기 → MCP 응답 마지막 블록을 실제 어댑터·가짜 엔진으로 확인했다. 실창에서 영어를 골랐던 정확한 이유나 실제 Claude의 지시 준수는 입증하지 않았다.
2. **완료**: values 재개 검색과 사이트 허용 링크 모두 기존 `arrival_finishes`를 탈 수 있으므로 “완료 판정 자체가 빠진다”는 가설은 맞지 않는다. 확인된 약점은 작업 전의 목적과 도착 증거가 있어도 목적 판정을 새 페이지의 선택지와 함께 다시 해야 한다는 점이다. 실창 확률/페이지 상태는 미수집이므로 당시의 정확한 분기는 추정이다. 이미 입력한 값으로 수행하는 읽기 전용 GET 검색은 제출 전에 단독 검색 여부를 묻고, 진입의 사이트 허용 대상 링크는 기존 `open_only`를 권한 질문 전에도 묻는다. 높은 확신으로 단일 작업이고 새 일반 페이지에서 올바른 검색 파라미터/정확한 링크 URL을 검증하면, 새 페이지에서 후속 선택이 애매해도 `done`을 낸다. 그 외 기존 도착 판정을 유지한다. 잘못된 쿼리, 후속 작업이 남은 요청, 사이트 거절·미응답은 이 증거로 완료하지 않는다. 답변 작성이나 링크를 누르는 권한을 늘리지 않는다.
3. **일시중지**: 요청 진입 시점에 이미 잡힌 중지는 정상적으로 '사용자 차례'가 된다. 하지만 진입 후 물리 입력 전 사람이 개입하면, 취소된 액션 리스에서 일반 권한 오류가 돌아올 수 있다. overlay의 거부 처리에서 **미전송이 증명됐을 때만** 기존 카드 중지 판정을 다시 확인해 이미 있는 `user-hold` 경로로 보낸다. 루프가 실패 액션을 발행하거나 재시도하지 않고 `human_step`으로 끝낸다. 실창 사례가 정확히 어느 경합이었는지는 미확인. 이미 전송됐거나 효과가 미확인인 동작은 단순 중지로 세탁하지 않는다.
