**확인**: 첫 턴에만 시스템 지시가 들어간다는 가설은 틀렸다. 재생 시험에서 새 스레드와 재적재된 후속 스레드의 `appendPrompt`에 모두 기존 `REPLY_LANGUAGE`가 있다. 반면 `runBrowserEntryOn`이 넘긴 `report_to_user` 메모는 `additionalContext.egdesk_browser_task`로 현재 턴에 실리고, `claudeTurnContent`는 메모와 사람 원문을 하나의 SDK user 메시지에 배치했다. 그 메시지 안에는 답 언어 지시가 없었다. `continueBrowserRunTurn`도 메모·원문을 직접 `startTurn`에 보냈다. **추정**: 영문 보고 메모가 현재 답의 언어 선택에 영향을 주었을 수 있다. 그날 모델이 영어를 선택한 정확한 이유는 확인하지 않았다.
