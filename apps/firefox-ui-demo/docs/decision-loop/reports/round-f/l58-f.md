## 알려진 한계 (미검증 위험)
- 이 세트는 실창을 돌려 보지 않았다. 구조·URL·스크립트 문법만 테스트함. 다음을 첫 실행 때 확인: (1) `go-card.mjs`가 큰 data: URL 도착을 `currentURI.spec` 문자열 일치로 판정하는데 Firefox가 data: URL을 정규화하면 setup이 실패할 수 있음. (2) data: 문서(불투명 origin)에서 이 대화 사이트 허용 질문·`window.open('about:blank')` 팝업 차단 여부(rws-05). (3) rws-13은 카드 재개가 사람 조작이면 후속 턴 체크가 FAIL할 수 있음(그 자체가 기록할 발견). (4) rws-11 answerRe '테스트'는 질문에도 있어 약함.
- 실계정 없이 재현 못 하는 것: 실제 기관 포털의 서버 저장/접수 지연과 인증(공동인증서·휴대폰 승인·OTP), OS 네이티브 파일 선택창 동작 자체, 이미지 기반 보안키보드의 픽셀 좌표, 로컬 파일 권한·첨부 형식 거부(서버측 검증), 프로필/확장 권한 재시작(BF-07), Sheets 가상 그리드·클립보드·undo(BF-03), 배포 revision/DB 불일치(BF-08), 메일 발송·DNS/SSL 등 외부 시스템 receipt(0023/0024), 장기 처리 상태.
