## 원인 (코드로 확인, 실창 재현은 Main)
runBrowserReflex POST 분기: 클릭 뒤 ① 클릭 접수의 url postcondition은 도착 문서를 읽어야 하는데, 클릭이 문서를 바꾸면 browserToolAct가 after=null을 돌려 `postcondition-unverified`. ② 폴백 `egdesk_browser_wait(load)` → `observe`로 도착 문서를 보고 `snapshot.url === to`를 요구. 도착이 Firefox JSON 뷰어라 자식 액터가 스냅샷을 못 주면 wait/observe가 실패(BROWSER_WAIT_OUTCOME_UNKNOWN 등)하고, catch가 이를 삼킨 뒤 곧바로 `tool_failed` 로 종료. 즉 '주소 비교 불일치'가 아니라 '비교할 도착 사실 자체가 없음'이 원인. 부모(surface)는 top-level 주소를 알지만(xulBrowser.currentURI) 오류 응답에 실리지 않았다. 뷰어가 실제로 관찰 불가인 점은 코드 정황(추정 원인과 일치)이며 엔진 실행으로 직접 확인하지는 않았다.
