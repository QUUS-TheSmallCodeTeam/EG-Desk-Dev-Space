# L44-d: EG-Desk Firefox 프로세스 창만 녹화 (브랜치 lane/d-window-recorder)

## 구조
- Swift CLI `egdesk-screen-recorder`(임시 이름): `--pid --out [--fps 5] [--max-sec] [--scale]`. 소스 `apps/firefox-ui-demo/helper-native/screen-recorder/main.swift`(새 폴더, WM 라우팅 없음: 네이티브 소스 전용 위치가 없어 기존 `helper/`(Node)와 분리해 새로 둠). 빌드 `scripts/build-screen-recorder.sh` → `apps/firefox-ui-demo/.tmp/bin/`(git 무시 확인).
- 브리지: `helper/egdesk-screen-recording.mjs`. 기본 소스 `egdesk-windows`. **고정 사각형 'os'(ffmpeg avfoundation)와 osCaptureRegion 제거**, `source:'os'`는 400. 소스는 `window`(L37 본창 MediaRecorder)와 `egdesk-windows` 둘.
- PID: 요청 본문에서 받지 않음(`pid` 필드는 unknown-field). 창(overlay `eg-desk-surface.uc.js` locate 응답에 `Services.appinfo.processID` 추가)이 알려 주고, 없으면 `no-firefox-pid`로 거부.

## 필터 방식과 다른 앱 배제 근거
- `SCShareableContent`에서 `owningApplication.processID == pid`, 화면에 있는 40pt 이상 창만 골라 `SCContentFilter(display:including:windows)`. "포함한 창만" 방식이라 목록에 없는 창(다른 앱, 알 수 없는 창)은 앞에 있어도 프레임에 합성되지 않음. exclude 방식은 쓰지 않음(시험이 소스에서 금지 확인).
- 1초마다 창 목록 재조회 → 바뀌면 `updateContentFilter`(대화상자 포함/닫힘). 영상 크기 = 창이 가장 많은 디스플레이 크기 × scale, 창 밖은 빈 배경.
- 순서: 캡처 → 필터(범위) → 마스크(CVPixelBuffer 제자리) → H.264 MP4(AVAssetWriter, fragment 5초).
- 권한 없음: `screen-recording-permission` 오류 JSON + 종료 1, 브리지는 422 거부(사유·상세를 sidecar에). 6초 안에 프레임 0이면 `no-frames` 오류(빈 영상 금지). 창 없음 `no-window`.
- 실제 확인: EG-Desk PID 86937로 4초 녹화 2회(18프레임 등): 본창 + Firefox '소프트웨어 업데이트' 대화상자만 찍힘. 계산기(앞으로 띄움, 위치 691,51 230x408로 대화상자 영역과 겹침)를 앞에 둔 채 녹화 → 프레임에 계산기 없음. 파일·프레임 삭제 완료, 계산기는 내가 띄운 것이라 종료.

## 마스크 상태
- 녹화기 쪽: stdin `{"mask":[{x,y,w,h}],"rev":N}`(디스플레이 pt 좌표)를 받아 이후 프레임 인코딩 전 검게 칠함, stdout `mask` 이벤트. 브리지 쪽: `setMask(boxes)`와 창 보고 `state:'mask'`(boxes: x,y,width,height) 수신 → stdin 전달, rev·시각·칸 수를 sidecar `maskRevisions`에.
- **창 쪽 생산자(오버레이의 민감 칸을 화면 좌표로 바꿔 주기적 전송)는 이번에 연결 안 함 → sidecar `mask:'none'` + 이유 명시, 다음 일.** 켜 두면 EG-Desk 자체의 민감 칸은 보임(다른 앱은 안 들어감).
- sidecar: `source`, `filter{kind,pid,windowCount,windowIds}`, `intervals[{fromMs,toMs,windows,windowIds,maskRevision}]`, `frames{count,masked}`, `recorder{video,display,fps,scale}`.

## Main 실창 확인 절차
1. `bash apps/firefox-ui-demo/scripts/build-screen-recorder.sh`(소유자 체크아웃에서 1회). 브리지를 `EGDESK_SCREEN_RECORDING=on`으로 켜고, **EG-Desk 창은 새 overlay(pid 보고)가 필요하므로 앱 재시작**. 화면 기록 권한은 브리지를 띄운 앱(터미널 등)에 필요.
2. `node scripts/real-window-qa/record.mjs start --max-sec 20` 후 다른 앱(예: 계산기·메모)을 EG-Desk 위에 겹쳐 앞에 둠 → 10초 뒤 `stop`.
3. 파일에서 프레임 추출(`ffmpeg -ss 5 -i f.mp4 -frames:v 1 x.png`): 다른 앱이 없고 EG-Desk(+그 대화상자)만 있어야 함. sidecar `filter.pid`/`intervals` 확인. 확인 뒤 파일 삭제.

## 남은 위험
- 마스크 생산자 미연결(위). 영상은 한 디스플레이만(창이 가장 많은 쪽, 시작 시 고정, 창이 다른 디스플레이로 가면 못 따라감). 숨김/최소화 창은 안 찍힘. 같은 PID의 다른 창(예: Firefox 팝업 메뉴)이 isOnScreen이면 포함. PID는 Firefox 주 프로세스만(콘텐츠 프로세스 창 없음, 정상). 이 PID가 가진 창이 EG-Desk 말고 일반 Firefox 창이면 그것도 찍힘(EG-Desk 전용 프로필 프로세스라는 전제).
- 앱 재시작 전 구 오버레이는 pid를 안 보내 `no-firefox-pid`로 거부됨(조용히 잘못 찍지 않음).
