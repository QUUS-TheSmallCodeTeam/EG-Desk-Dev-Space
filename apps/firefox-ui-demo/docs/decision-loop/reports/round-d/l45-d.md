# L45-d: 녹화기 writer 중단 (10.05초에서 끊김)

## 원인 (확정)
- 실제 오류: AVAssetWriter `AVFoundationErrorDomain -11800`, underlying `NSOSStatusErrorDomain -16341` ("unknown error").
- 원인: `movieFragmentInterval = 5s`(조각화 MP4)를 ScreenCaptureKit 라이브 프레임에 쓸 때 writer가 조각 경계(약 10~35초)에서 무작위로 실패. 다른 후보는 배제.
  - 필터 갱신/크기 변화: 실패 순간 windows 이벤트 없음, 프레임은 전부 1512x982 scale 2.0, contentRect 동일.
  - 비단조 타임스탬프: droppedOrder 0, 프레임 간격 199~224ms 정상.
  - 첫 프레임 기준 startSession: PTS를 0 기준으로 다시 맞춰도(rebase) 35.5초에 동일 실패.
  - 마스크 IOSurface 직접 쓰기: 이 재현에는 마스크 없음(maskedFrames 0)인데도 실패.
- 측정(같은 머신, EG-Desk PID 12747, 5fps, 조각화 켬): 100초 중 4회 실패(25.7/30.1/20.3/10.2초 구간), 90초 1회, 20초 0회. 조각화 끔: 75초 0회. 조각화 켠 상태에서만 재현.
- 기존 결함이 "조용"했던 이유: 실패 뒤 `w.status == .writing` 검사에서 append를 건너뛰기만 하고 오류를 안 읽었고, 종료 때 `localizedDescription`(상세 비어 있음)만 보고.

## 수정
- main.swift: `movieFragmentInterval` 제거. 오류 전체(domain, code, 이유, underlying 사슬)를 `segment-closed` 이벤트에 기록. writer 실패·append 실패·프레임 크기 변경 시 해당 구간을 닫고 다음 프레임에서 새 구간 파일(`<id>.mp4`, `<id>.s2.mp4`, ...)로 이어 씀. 비조각화 MP4는 닫아야 재생되므로 60초마다 구간을 닫고 새로 엶(`roll`, 비정상 종료 시 손실 최대 60초). 시간 역행 프레임은 건너뛰고 세며(droppedOrder), writer 바쁨 누락(droppedBusy)도 셈. 실패 구간에는 직전 프레임 10개의 PTS 간격·contentRect·dirty 수 기록. 정지는 stdin q·SIGINT·SIGTERM 그대로(마지막 구간 finishWriting 대기).
- 브리지(egdesk-screen-recording.mjs): 사이드카 `segments`(구간별 file, reason, 시간 범위, frames, ok, 실제 error, bytes, sha256, 누락 여부), `segmentFailures`, `segmentGaps`(구간 사이 공백 ms), `droppedFrames`. 정지 때 구간 파일마다 sha256·bytes 계산. 검증(verifyRecordingFiles)은 구간 파일 방식 지원: 각 구간 존재·hash 일치·ffprobe 디코드 확인, 실패 구간은 lostSegments로 드러냄. ok = recorder가 ok라 한 모든 구간이 검증됨.
- 새 화면 문구 없음.
