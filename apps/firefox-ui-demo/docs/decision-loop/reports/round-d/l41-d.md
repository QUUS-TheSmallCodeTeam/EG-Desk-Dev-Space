## API 형식 (공식 문서 원문 확인)
출처: aistudio.google.com/docs/decisions-api, /api-reference/decisions/create-decision, /docs/models/gemini-decision-1, /docs/rate-limits, /docs/troubleshooting (2026-11-28 조회).
- `POST https://generativelanguage.googleapis.com/v1beta/decisions`, 헤더 `x-goog-api-key`. 본문 `{model:"gemini-decision-1", input: 문자열|콘텐츠블록[], questions:{<id>:{type, instructions, criteria}}}`.
- 질문 3종: `noul`(예/아니오; criteria 선택 `{true_description,false_description}`), `choice`(criteria = {옵션id: 설명} 맵, 옵션 2~255, 키는 UTF-8 바이트순 정렬, 동률은 앞 키), `score`(criteria = 설명 배열 2~255, 0부터).
- 응답 `answers:{<id>:...}`: noul `{noul 0.01~0.99, confidence}`, choice `{choice, probabilities{}, confidence}`, score `{score, legend, probabilities{}, confidence}`. 확률은 answers 안, confidence = 최고 확률(noul은 max(p,1-p)).
- `usage:{total_input_tokens, input_tokens_by_modality[], total_output_tokens(항상 0), total_tokens}`. 입력 블록: text/image/audio/video/document.
- 차단: HTTP 200 + `prompt_feedback.block_reason`(safety|other|blocklist|prohibited_content|image_safety), answers 비어 있음. 오류: 표준 Google `{error:{code,status,message,details}}`; 429 RESOURCE_EXHAUSTED(재시도 대상), 400/402/403은 재시도 금지.
- 한도(무료): 200 RPM / 5만 TPM / 일 1만 요청. Tier1 1,500 RPM/100만 TPM.
- 문서에 없는 것(추정): 429 본문의 분/일 구분 필드. quotaId에 `PerDay`가 있으면 일 한도로 추정해 분류(실제 429는 못 만들어 미검증). 400 키 오류 reason `API_KEY_INVALID`도 Google 공통 관례 기준.

## 무료 티어가 한 턴에 주는 영향
- 한 턴 결정 호출 약 18,000~20,000토큰 → 분당 5만 토큰 한도에서 **분당 약 2~2.5턴**이 상한. 연속 턴이나 병렬 에이전트(턴 겹침)면 429 rate_limited가 쉽게 남. 이 경우 기존 경로대로 실패(P2). 일 1만 요청은 호출 수 기준이라 여유(한 턴 호출이 수십 번이어도 하루 수백 턴).
- 한 요청이 5만 토큰을 넘으면 그 자체로 한도에 걸릴 수 있음(현 입력은 2만 내외라 한 번에는 통과).
- 무료 티어 내용은 구글 제품 개선에 쓰임: 페이지 텍스트·터미널 출력·대화 맥락이 학습에 쓰일 수 있음. 송신 게이트(U9)는 허용 종류만 보내지만, 개인정보 민감 데이터는 무료 키 대신 유료 키 권장.
- 로컬 월 토큰 집계는 usage.total_input_tokens로 반영됨(분당 한도는 로컬에서 미관리).

## 남은 위험
- 429 분/일 구분과 키 오류 400의 실제 본문은 미검증(위 추정). 분당 한도에는 로컬 속도 제한 없음.
- Gemini choice는 한도 안에서 항상 확률을 분배(문서): 후보에 '해당 없음'이 필요한 질문은 호출부가 기존처럼 처리.
- Gemini 베타(v1beta): 형식 변경 가능. verifyKey는 Gemini에서 질문 1개로 동작(실호출 확인은 안 함).
- 이미지는 data URL만 인라인 변환(그 외 https는 uri). 실제 Board 이미지 요청은 실호출 안 함.
- 워밍업(EGDESK_DECISION_WARMUP)·send-stamp는 OpenAI 엔드포인트 전제 코드가 있어 Gemini에선 stamp만 통과(미적용).
