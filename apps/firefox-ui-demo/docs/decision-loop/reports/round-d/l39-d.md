## 한 일
`egdesk-browser-reflex.mjs`에 `stepPageEvidence`(임시 이름) 추가, `decideReflexStep`의 증거 조립이 사용. 본문 켬일 때 **컨트롤 목록(controlLines)을 본문 앞에** 싣고 머리말로 "고를 선택지는 사람 말과 이 컨트롤에서 나온다. 아래 Visible text는 페이지 상태·목표 달성·페이지가 말하는 내용의 근거이지 선택지 목록이 아니다"를 붙인다. 본문 자체(조각 400자, 4,000자 상한·통째 중단)·`Visible text:` 표지·문턱은 그대로. 본문 끔이면 이미 컨트롤이 본문 줄이므로 두 번째 목록 없음.

한계(솔직히): 한 요청 안에 선택 질문과 페이지 상태·goal_met 질문이 함께 들어가 질문별로 증거를 따로 줄 수 없다(나누면 요청 수·기존 시험 다수가 바뀜). 그래서 "질문별 싣기"는 요청 단위 순서·머리말로 구현했다.

| 질문 종류 | 싣는 것 |
|---|---|
| 컨트롤 선택(next_step, step_link/press, choice_requested, select_i) | 사람 말(Goal) + 컨트롤 목록 먼저, 선택지는 질문 안 |
| 페이지 이해(goal_met, page_unclear 등 페이지 상태, read_here, 결과 판정) | 같은 요청의 Visible text(본문, 머리말에 근거 용도 명시) |
