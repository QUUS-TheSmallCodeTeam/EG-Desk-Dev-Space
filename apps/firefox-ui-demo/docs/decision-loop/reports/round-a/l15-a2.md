- 실제로 `needs_value`를 내보낸 경우에만 그 공개 이름과 당시 `documentId/url/ref`를 같은 작업에 보관한다. 다음 값의 키가 공백 정리 후 일치하고 새 관찰의 같은 문서·URL·ref가 여전히 허용된 입력 후보면, 기존 바인딩·입력 코드로 한 번 입력한다. 이름만 같은 다른 요소로 바로 입력하지 않는다. 문서 식별자가 없거나 대상이 바뀌면 기존 매핑과 결정을 거친다. GET 허용 범위와 `typed_search`는 그대로다.
