## 4. 동작
"구글에서 장화 신은 고양이 검색해서 첫 결과 열고 줄거리 요약해줘" (구글 카드 Chat 조작 허용):
1. 대화 모델이 `egdesk_browser_task({ goal, values? })` 호출. cardId 생략 가능(조작 허용 카드가 하나면 그 카드; 런타임 관문 `pageToolGate`가 첫 조작 카드를 `egdesk_browser_navigate` 권한으로 검사).
2. 결정 모델 루프(기존 `runDirectTask`)가 단계를 결정:
   - 주어진 값은 먼저 입력(같은 요청에 페이지 상태 질문을 실어 일반 화면일 때만).
   - 값이 없고 "글이 필요"하거나 "1순위가 입력칸인 불확실" 단계면, 사람 메시지와 goal에서 코드가 자른 구간 중 하나를 결정 모델이 고름(+ none). none이면 `needs_value`.
   - 검색 버튼은 기존 GET 증명(readOnlyPress)을 통과하면 바로 제출(사용자 16:00 허용). 결제·전송·삭제·권한은 후보 아님.
   - 구글 `<textarea role=combobox>` 검색칸도 입력칸(이 경로만).
   - 이동 뒤 주소 사후조건이 실패로 읽혀도, 다시 관찰한 주소가 규칙에 맞으면 성공: 링크는 같은 호스트·경로(쿼리·조각 무시) 또는 링크 사이트 안의 리다이렉트, GET 검색은 같은 출처·경로 + 보낸 파라미터와 값이 그대로(덧붙은 ia·utm·fg 등 무시). 출발 주소 그대로면 실패 유지.
3. 결과 페이지에서 길이 안 보이면 같은 사이트 요소 먼저, 다른 사이트 링크(나무위키·위키백과, site 표시)를 `needs_guidance` 선택지로 돌려줌.
4. `guidance: { choose }`로 다시 부르면, 같은 사이트 요소는 바로 실행(by: model), 다른 사이트 링크는 페이지 도구의 누르기(새 관찰에서 주소로 찾고, 카드의 사이트 질문 → 허용되면 이동).
5. 새 페이지에서 루프가 계속, 끝나면 `done`, 확신 없으면 `needs_guidance`(선택지 없음, next read_the_card) → 대화 모델이 읽고 요약.

직접 입구(`createDirectBrowserEntry`)의 새 선택형 `fieldText: () => boolean`(기본 꺼짐): 켜면 위 2번의 구간 고르기·값 먼저 입력·텍스트 콤보박스를 입구 루프도 씀. 실창 DuckDuckGo 흐름(진입 → 구간 '장화 신은 고양이' → GET 제출(ia=web 덧붙음) → done → 닫힌 쪽지 한 번)을 시험으로 고정. 꺼지면 예전처럼 첫 단계에서 멈춤(detail_needed)도 시험으로 고정.

결과(닫힌 단어): `{ status: done|needs_value|needs_guidance|human_step|cannot, code?, ask?: {field, kind}, options?: [{id, label, site?}], controls?, next?, taskId, steps: [{op, target, valueName?, ok, ms, by?}], page: {title, host}, elapsedMs, forYouOnly }`. goal 없이 부르면 열린 작업(공유 저장소면 입구가 멈춘 작업도)을 이어 감. 대화 키는 `run.clientThreadId` 우선(입구와 같음).

단계 이벤트 계약(`taskStepEvent`): `{ taskId, cardId, seq, op, target, valueName, ok, ms, by: 'decision'|'model', code?, status? }`, op = open|submit|press|fill|scroll|end(호출의 마지막, status). 기다림은 이벤트 없음(반사 보고에 op 없음). 값 원문·주소·본문 없음. 작업 도구는 `runtime.browserTaskStep(run, event, { taskId, cardId })`로, 직접 입구는 `onStepEvent(run, event)`로.
카드 act 요청: 작업 도구 경로만 `actor: 'decision'|'model'`을 실음(직접 입구는 기존처럼 callId `.reflex-` 판별).

4. **통합 때 맞출 것**: L5 `egdesk-browser-task-turn.mjs`의 같은 이름 상수 `BROWSER_TASK_TOOL_NAME`은 내 모듈 것을 가져다 쓰게(상수 하나).
