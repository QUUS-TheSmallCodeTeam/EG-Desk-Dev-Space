## 2. 수정 (최소)
1. **페이지 도구가 직접 사이트 질문을 함** (`egdesk-page-tools.mjs`, `press`): 링크가 **대화 사이트 밖**(`evaluateNavigation` 결과 `outside-site`)이고 판정이 "승인 필요, 근거 없음(unproven)"일 때만, 도구가 같은 run, 같은 카드에서 `egdesk_browser_request_site`(기존 카드 질문 "Agent가 이 대화에서 … 사이트도 열려고 합니다. 허용할까요?")를 직접 던짐. 허용되면 **새 관찰**로 같은 링크를 확인한 뒤 **한 번** 이동(`via: 'site'`), 거절이나 무응답이면 아무것도 움직이지 않고 닫힌 말(`not_done`, `BROWSER_NAVIGATE_OUT_OF_SCOPE`, `site: site-refused | site-pending`). 사람의 동의는 이 사이트 질문 하나로 충분(채팅 승인과 이중 질문 없음). 로그인, 결제 등 person 분류와 제출, 삭제 어휘 링크는 이 분기 이전에 이미 갈라져 그대로입니다.
2. **질문하는 카드를 앞으로 가져오고 화면에 보이게** (`eg-desk-surface.uc.js`, `allow-site` 처리): 질문 직전에 카드 z-index를 올리고 기존 `revealOpenCanvasCard(card, { kind: 'browser' })`로 시야에 넣음. Claude가 직접 `egdesk_browser_request_site`를 부를 때(그리고 Codex)도 같은 효과.
- 보류(제안, 승인 대기): 질문이 55초 안에 답을 못 받아도 Chat에 알림이 없는 것은 그대로입니다. 알림을 추가하려면 새 문구가 필요해 하지 않았습니다.
