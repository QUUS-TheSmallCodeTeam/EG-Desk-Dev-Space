## D5 남은 기본 도구: 끄는 것과 남기는 것(이유)
- **끔(추가)**: `Agent`(옛 이름 `Task`), `ListAgents`: 하위 에이전트는 자기 도구로 일하고 그 메시지는 EG-Desk에 가려져(번역기는 호출당 한 줄만 남김) 하네스 밖의 일이 됨. `EnterPlanMode`, `ExitPlanMode`: 계획 모드는 CLI 자체 흐름이고, 그 승인(명령·파일 변경·질문이 아닌 도구)은 EG-Desk 권한 중개가 거절(`unsupportedTool`)해서 **계획 모드에 들어가면 나올 수 없게 됨**(시험이 거절을 직접 확인). `SendToProjectContext`, `DesignSync`: 대화 밖으로 새는 도구(바깥 목록에 추가). 합친 `--disallowedTools` = 명령·파일 5 + 읽기 3 + 바깥 14 + 흐름 5 + computer-use 규칙 2.
- **남김**: `AskUserQuestion`: EG-Desk가 처리함. 중개가 이를 대화의 **질문 카드**(`item/tool/requestUserInput`)로 바꾸고 사람의 답을 `updatedInput`으로 돌려줌(시험이 경로 확인). `ToolSearch`: D6의 보험(EG-Desk 도구가 어떤 이유로 지연되어도 닿는 길이라 끄면 도구가 안 보일 수 있음). `TaskStop`: 이 대화의 작업 중지. `ReportFindings`: 바깥 효과가 문서에 없고 세션에 구조화된 결과를 돌려주는 것으로 **추정**(미검증, 화면에서 호출되면 알려 주세요).

## D6 EG-Desk MCP 도구의 지연 로드(ToolSearch 왕복) 없애기
근거 문서: Claude Code 공식 문서 `code.claude.com/docs/en/mcp`(Tool search 절)와 `/env-vars`, 변경 기록 2.1.121.
- 서버 설정 `alwaysLoad: true`: "그 서버의 도구는 `ENABLE_TOOL_SEARCH`와 관계없이 처음부터 컨텍스트에 올라간다", 모든 서버 종류에 적용. EG-Desk가 주는 `--mcp-config`의 'sdk' 서버 항목에 넣음(`{type:'sdk', name:'egdesk', alwaysLoad:true}`; 전송 계층의 검증은 이 키 하나만 통과시키도록 확장).
- 도구별 표시: `tools/list`의 각 도구 `_meta: {"anthropic/alwaysLoad": true}`(문서의 "Mark a tool to load upfront"), 서버 쪽 값이 안 먹을 때를 대비한 두 번째 길.
- 환경: `ENABLE_TOOL_SEARCH=false`("모든 MCP 도구를 처음부터 올림, 지연 없음"): 이 프로세스에는 EG-Desk의 서버 하나뿐이라(`--strict-mcp-config`) 영향 범위가 EG-Desk 도구뿐. 세 길 중 문서상 가장 확실한 것.
- 하네스 켠 스레드만 적용(다른 Claude 스레드와 플래그 끈 경우는 설정이 그대로, 시험이 확인). 시험은 `--mcp-config` argv, 프로세스 환경, `tools/list` 응답을 직접 검사. **실제 CLI가 이를 지켜서 ToolSearch 왕복이 사라지는지는 화면 검증 몫**(활동 기록에서 `ToolSearch → egdesk_*` 쌍이 없어야 함). 주의: `alwaysLoad`는 시작 때 서버 도구를 기다림(문서: 5초 연결 한도).

## D4 기억·지침 문구 (L7 협조)
하네스 지침(`--append-system-prompt`에 실리는 모델용 문장, 사람에게 보이는 문구 아님)에 추가: "EG-Desk가 기억과 상시 지침을 관리한다: 사람이 적용하거나 되돌릴 수 있는 지침 기록에 두고 필요한 것을 턴에 실어 준다(지침이 어디까지 왔는지는 턴의 EG-Desk 줄이 말해 준다). 사람이 기억하라거나 답 방식을 바꾸라고(짧게, 다른 톤) 하면 이번 턴부터 따른다. 자기 기억에 저장했다고도, 아무것도 못 남긴다고도 말하지 말고, EG-Desk가 주는 상태를 덧붙이거나 뒤집지 마라." L7의 `egdesk_nunchi` 상태 줄("후보로 남겼다 / 적용 중 / 직접 기억할 필요 없다")과 겹치지 않고 모순되지 않게 L7과 맞춤.
