# L8 u12: 사이트 허용 직후 이동이 "화면 정보가 오래됐다"로 멈춤 (D25)

- 브랜치 `lane/u12-site-stale` (기준 int/c14 `0f27223`), 작업 사본 `$L/wt-l8-u12`, 커밋 `524c43b`. 게이트는 4절. 새 문구 없음.

## 1. 실창 기록으로 좁힌 지점
채팅 저장소(도구 이름, 시각, 코드만): 21:48:29.8 누르기 -> 21:48:30.595 `request_site` **site-allowed**(허용 통과) -> 21:48:30.597 `observed`(허용 직후 새 관찰) -> 21:48:30.642 **`browser.tool.failed code=BROWSER_OBSERVATION_STALE`**(관찰 뒤 45ms, 즉 헬퍼 안의 즉시 거절이 아니라 카드까지 갔다 온 뒤의 "보내지 못함" 응답). 다시 읽고 다시 눌러도 21:48:37.4 같은 순서로 같은 코드. 허용 단계와 정책은 통과했고, **이동 요청 한 번이 카드에서 "관찰한 문서와 현재 문서가 다름(보내지 않음)"으로 돌아온 것**입니다.
- 이 코드는 카드가 "보내지 못했다"고 답하는 모든 경우(문서 지문 불일치, 이동 허용 재검사 거절 등)를 가리키는 하나의 닫힌 코드라, 기록만으로는 그중 정확히 어느 검사인지 구분되지 않습니다(`assertGuardedDocumentCurrent`의 창 id, 주소 비교 또는 허용 재검사). 재생(진짜 전송 계층과 카드 의미를 옮긴 클라이언트)에서는 재현되지 않았고, 카드 화면 코드는 여기서 실행할 수 없습니다.

## 2. 한 일 (페이지 도구의 허용 직후 경로만, 좁게)
1. **허용 직후 링크를 ref가 아니라 "같은 주소, 같은 글자"로 새 관찰에서 다시 찾음**: 이전에는 같은 ref와 주소가 둘 다 같아야 했습니다. 페이지가 다시 그려져 ref가 바뀌면 `PAGE_REF_UNKNOWN`(엔진에는 "오래됨"으로 보임)이 되었을 수 있습니다. 이제 주소와 표시 글자가 같은 `<a>`를 찾아(가능하면 같은 ref 우선) 이동하고, **주소나 글자가 달라졌으면 이전처럼 거절**(이동 없음)합니다.
2. **새 호출 id로 관찰**: 허용 직후의 "새 관찰"이 같은 호출 id(`...obs`)를 다시 써서 헬퍼의 호출 중복 제거가 **이전 관찰 결과를 되돌려줄 수 있었음**(같은 인자의 같은 호출 id는 이전 결과 반환). 관찰마다 고유 id(`siteobs1`, `siteobs2`)를 씁니다.
3. **한 번 더 관찰 후 이동 1회**: 이동이 `BROWSER_OBSERVATION_STALE`로 거절되면(보내지 않았음이 확실한 경우), 새 관찰을 한 번 더 하고 이동을 한 번만 다시 시도합니다(최대 2회, 그 이상 반복 없음). 확정된 원인이 일시적 문서 변경이면 여기서 풀립니다.
- 재생 시험 2건 추가(총 11건): ref가 바뀌어도 이동 1회, 첫 이동이 stale로 거절돼도 두 번째 관찰 뒤 이동(첫 이동은 거절로 남고 두 번째가 감), 주소나 글자가 바뀌면 거절. 같은 사이트 재요청 즉시 허용은 u10 시험이 계속 고정.

## 3. 솔직한 한계와 다음 실창
- 위 3가지로 풀리는 것은 "ref 재배번호, 중복 제거로 낡은 관찰, 일시적 문서 변경"입니다. 실창의 stale이 **결정적**(두 번 다 같은 코드)이었으므로, 원인이 카드의 문서 지문 비교(`innerWindowId`, `browsingContextId`, 주소 불일치) 쪽 결정적 불일치라면 이번에도 같은 코드로 멈출 수 있습니다. 그 경우 화면 코드(`browserToolNavigateChrome`의 `assertGuardedDocumentCurrent`와 이동 허용 재검사)에서 어느 쪽이 던지는지가 필요합니다: 두 곳 모두 같은 "보내지 않음" 표식을 쓰므로 카드가 던지는 오류 메시지를 콘솔에서 보면 한 번에 갈립니다("Browser observation is stale" 또는 "outside the allowed sites [이유]").
- 다음 실창 확인: 같은 흐름 한 번. 이동하면 해결, 또 stale이면 위 콘솔 메시지(카드 chrome 콘솔의 `Browser observation is stale ...` 또는 `outside the allowed sites [...]`)를 알려 주세요.
