# L3 u7 — D21: 같은 턴에 편집한 파일의 편집 전 본문이 점검 근거로 쓰인 문제

브랜치 `lane/u7-check-stale-file` (int/c14 `dc4890a` 위). 실제 Codex와 Claude 실행 없음(L5의 재생 세계: 진짜 런타임과 어댑터와 EG-Desk 도구, CLI는 스크립트, 결정 모델은 증거에 있는 낱말로 지지 여부를 판단하는 가짜).

## 원인
`EGDESK_DRAFT_CHECK_FILES=on`일 때 미리 넣은 작업 폴더 파일의 본문은 **턴이 시작될 때 읽은 본문**이 점검과 고쳐 쓰기의 증거가 된다(u5). 그 턴에서 EG-Desk 편집 도구가 같은 파일을 고치면, 증거에는 "start 스크립트가 없는 package.json"이 남는다. 편집 사실 항목(`ownEditEvidence`)은 경로와 줄 수뿐이라 "start 스크립트를 추가했다"의 낱말은 어느 증거에도 없고, 점검은 맞는 문장을 모순으로 보며 고쳐 쓰기는 같은 증거로 "변경 내용을 확인할 수 없다"를 만든다(05:26 사건과 같은 모양).

## 고침 (최소, 이 경로만, 새 사용자 문구 없음)
- `refreshEditedFiles(run, evidence)`: 증거 중 **파일 항목**(`kind: 'file'`, id `workspace:<상대경로>`)이면서 **같은 실행에서 EG-Desk 편집 도구가 건드린 경로**(`run.ownEdits[].path`)는 **지금의 파일 본문**으로 바꾼다(`readNowWorkspaceFile`: 폴더 안, 일반 텍스트 파일, 앞부분만, 폴더 밖 링크나 NUL 바이트는 null). 항목은 하나만 남는다(옛 것을 곁에 두지 않음). 읽을 수 없으면(삭제 등) **항목을 뺀다**(옛 본문을 남기지 않음). 모델에게 가는 증거 문장은 "<경로> — as it is now, after the edit made in this turn:" 머리말(사용자에게 보이지 않음).
- 건드리지 않는 것: 편집이 없는 턴, 편집이 다른 파일에만 있는 턴(그 파일들의 항목은 턴 시작 본문 그대로), 바인딩된 폴더가 없는 실행, 파일 항목이 없는 경우(플래그가 꺼져 있으면 파일 항목 자체가 없다). 고쳐 쓰기는 같은 증거 목록을 쓰므로 함께 바로잡힌다. 되돌리기(undo)가 있었으면 지금의 파일이 진실이므로 지금 본문을 읽는 것이 옳다.

## 재생 시험 (`egdesk-d21-replay.test.mjs` 6건)
- 편집 전 본문(start 없음)을 미리 넣고 같은 턴에 `egdesk_edit_file`로 start 스크립트를 추가한 뒤 "package.json에 start 스크립트를 추가했습니다."라고 말하는 턴: **통과, 쓴 대로 게시**(파일이 실제로 바뀐 것 확인, 증거에 새 본문, 파일 항목은 한 개).
- 대조: 같은 턴에 새로고침을 끈 옛 동작은 같은 문장을 근거 없음으로 **잘라 낸다**(D21 재현: 빈 화면).
- 편집이 없는 턴은 기존 그대로(턴 시작 본문이 증거, "as it is now" 없음). 다른 파일만 편집한 턴은 그 파일 항목은 그대로, 편집한 파일만 새로고침.
- 편집한 파일을 지금 읽을 수 없으면 항목 제거, 편집이 없거나 폴더가 없으면 목록 그대로, `readNowWorkspaceFile`의 경계(폴더 밖, 링크, 이진, 디렉터리). 변이 5건 전부 검출.

## 실창 확인
`EGDESK_DRAFT_CHECK_FILES=on` 명시(묶음 밖), 같은 방에서 "package.json에 start 스크립트 추가" 제안 뒤 "응 그렇게 해": 기대: 편집이 적용되고 **"start 스크립트를 추가했습니다" 류의 답이 한 번에 통과**(보정 행 `as_written`, 점검 호출 1회, 고쳐 쓰기 없음). 음성 대조: 편집 없이 파일 내용을 묻는 턴은 D18과 같이 정상.

## 한계
편집 도구를 거치지 않고 다른 수단으로 파일을 바꾼 경우(예: 명령으로 `sed`)는 `ownEdits`에 없어 턴 시작 본문이 그대로 증거가 된다(명령의 사실만 증거). 다음 턴의 점검에서는 새로 미리 넣는 본문이 현재 본문이다. 새 파일: `helper/egdesk-d21-replay.test.mjs`.
