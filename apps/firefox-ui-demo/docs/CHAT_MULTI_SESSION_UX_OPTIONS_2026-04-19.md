# EGDesk Chat HUD 멀티세션 UX 옵션 (2026-04-19)

## 목표
- HUD를 메신저형 패턴으로 재구성: `목록 홈`과 `대화 화면`을 완전 분리
- HUD 기본 진입은 항상 목록 홈
- 멀티세션 전환 속도 강화: 단순 리스트가 아닌 우선순위 섹션 기반
- Canvas 모드는 기존 2-pane(split) 유지

## 공통 배치 원칙
- 상단 고정 영역: `제목 + 새 채팅 + 검색 + 필터(전체/개인/그룹)`
- 섹션 순서: `최근 작업 -> 읽지 않음 -> 고정 -> 전체`
- 대화 화면 진입 시 목록 요소 완전 숨김

---

## 안 1) 단일 홈 스크롤 + 단일 대화 전환 (Messenger Classic)

### 흐름
1. HUD 열기 -> 목록 홈 진입
2. 목록 홈에서 검색/필터/섹션 탐색
3. 채팅방 클릭 -> 대화 화면 진입
4. 상단 back 클릭 -> 목록 홈 복귀

### 멀티세션 배치
- 상단 고정바 아래에 4개 섹션을 하나의 세로 홈 스크롤로 제공
- `최근 작업`은 최근 업데이트 기준 상위 N개 빠른 접근
- `읽지 않음`/`고정`은 조건 충족 시 노출
- `전체`는 필터 범위 내 전체 채팅방 노출

### 장점
- 구현 복잡도/학습 비용이 낮고, 모바일 메신저 패턴과 가장 유사
- HUD 폭이 좁아도 일관된 정보 밀도 유지
- 상태 전환이 단순해 버그 표면적이 작음

### 단점
- 세션 수가 매우 많을 때 홈 스크롤 길이가 길어질 수 있음
- 섹션 간 중복 노출(예: 최근+고정)이 발생할 수 있음

### EGDesk 적합성
- HUD 고정 폭/고정 높이 구조와 잘 맞고, 현재 데이터 모델(pinned/unread/updatedAt/type)을 바로 활용 가능

## 안 2) 홈 탭형 멀티인박스 + 대화 전환 (Inbox Tabs)

### 흐름
1. HUD 열기 -> 홈 진입
2. 상단 탭(최근/읽지 않음/고정/전체) 중 하나를 선택
3. 탭별 목록에서 채팅방 선택 -> 대화 화면 진입
4. back -> 마지막 탭 상태로 홈 복귀

### 멀티세션 배치
- 섹션을 세로 나열하지 않고 탭으로 분리
- 한 번에 한 섹션만 보여 집중도는 높지만 전체 맥락은 약해짐

### 장점
- 대규모 세션에서 스크롤 피로 감소
- 섹션별 집중 탐색이 쉬움

### 단점
- 탭 전환 비용이 추가되어 “한눈 전환” 경험은 약화
- 현재 HUD 높이에서 탭/검색/필터를 함께 유지하면 상단 복잡도 증가

### EGDesk 적합성
- 중장기적으로는 유효하지만, 현재 HUD 즉시성(빠른 전환) 목표에는 1안 대비 불리

## 안 3) 2-열 홈 컴팩트 카드 + 대화 전환 (Dense Grid Home)

### 흐름
1. HUD 열기 -> 카드형 홈 진입
2. 좌측 열(최근/읽지 않음), 우측 열(고정/전체 요약) 탐색
3. 카드 클릭 -> 대화 화면 진입
4. back -> 카드 홈 복귀

### 멀티세션 배치
- 홈에서 두 열로 분산 배치해 초기 가시성 강화
- 전체 목록은 별도 확장/더보기로 분리

### 장점
- 정보 밀도를 크게 높일 수 있음
- “현황 대시보드” 느낌이 강함

### 단점
- HUD 폭(우측 패널)에서 2열은 터치/클릭 타겟 저하 위험
- 카드형 중첩 규칙이 복잡해 유지보수 비용 증가

### EGDesk 적합성
- 대형 HUD/데스크톱 전용이라면 가능하지만, 현재 오버레이 크기/가독성 제약과 충돌 가능성 큼

## 베스트 선택: 안 1 (Messenger Classic)

### 선택 이유
- EGDesk HUD의 현재 레이아웃/상태 모델에서 가장 안전하게 메신저형 전환을 달성
- 요구사항(홈/대화 완전 분리, back 복귀, 멀티세션 빠른 전환, 상단 고정바, 섹션 순서)을 최소 변경으로 충족
- Canvas split 2-pane과 충돌하지 않고 공존 가능

### 구현 반영 요약
- HUD 기본 진입은 `목록 홈`
- HUD 렌더는 `list`/`conversation` 2화면 분기
- 홈 섹션 순서: `최근 작업 -> 읽지 않음 -> 고정 -> 전체`
- 대화 화면에서 목록 렌더 제거(완전 숨김)
- back 버튼으로 목록 홈 복귀
- Canvas 모드는 기존 split 2-pane 유지
