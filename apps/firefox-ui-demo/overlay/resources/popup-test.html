Popup Capture Test

EG-Desk Browser 카드에서 이 페이지를 열고 아래 버튼을 하나씩 눌러 봅니다. 결과는 맨 아래 기록에 남습니다. 자동 회귀 시험은 scripts/verify-firefox-mcp-browser-popups.mjs가 같은 다섯 가지를 확인합니다.

  1. window.open(url, '_blank') · 기대: 새 Browser 카드, 반환값은 창 객체
  2. window.open(url, 'egdesk-login', 'popup,width=480,height=640') · 기대: EG-Desk 화면이 다른 창에 또 뜨지 않음
  3. 빈 팝업에 '로그인 끝' 메시지를 보내는 스크립트를 씀 · 기대: 아래 기록에 "메시지 받음"
  4. 빈 팝업이 1초 뒤 window.close() · 기대: 팝업 카드가 사라지고 이 카드는 남음
  5. window.open(url, '_blank', 'noopener') · 기대: 새 카드, 반환값은 null
