**읽기 전에**: 아래 '오늘 화면에서 달라진 것'은 코드와 Node 단위·조각 테스트 기준으로 적은 것이다(구현하는 동안에는 Firefox를 띄우지 않았다). 통합 뒤 04:35~05:00 KST에 Firefox를 두 번 띄워 화면을 봤고, **무엇이 화면으로 확인됐고 무엇이 아직 아닌지는 '실화면 검증 결과' 절에만 있다.** 그 절에 '확인됨'으로 적히지 않은 변화는 여전히 실화면 확인 전이다. 로그인과 실제 답변이 필요한 화면은 이번 검증 방식으로는 볼 수 없었다.

## 오늘 화면에서 달라진 것

### 맨 위 줄

- 화면에 Board가 없으면 왼쪽 이름이 'Board 없음' 대신 'EG-Desk'로 보인다. 오른쪽의 경고 삼각형(연결되지 않은 알림)은 사라지고, X(Board 닫기)는 열린 Board가 있을 때만 보인다.
- 자원 표시는 작은 원 네 개만 남고 CPU·RAM·R/W 글자가 사라졌다. 원을 누르면 뜨는 작은 창에 CPU·메모리·디스크 읽기/쓰기·네트워크 수신/송신이 한국어로 보인다.
- 그 작은 창은 숫자가 바뀔 때 깜박이지 않고, 숫자와 단위가 늘 같은 자리에 있다(대표님이 04:20에 알려 주신 결함의 수정). 속도와 크기는 세 자리 숫자(예: 1.00 KiB/s), 퍼센트는 소수점 없이 보인다.
- 넓은 창(폭 1200px 이상)에서는 검색창이 창 한가운데에 놓인다. 계정 원은 조금 작아지고 청회색이 됐다.
- 작업이 이 PC에 기록되면 이름 옆에 '이 PC에 기록됨 10:34'가 조용히 보이고(넓은 창), 실패하면 '기록 실패'와 [다시 기록]이 남는다. 창을 크게 보는 동안에는(창 폭 1600px 미만) 이 조용한 기록 표시가 숨고, 원래 크기로 돌아오면 다시 보인다 — 이름과 '○○ · 크게 보는 중'이 '…'로 잘리던 것을 실화면 검증 뒤 고친 것이다. '기록 실패'는 크게 보는 중에도 보인다.
- 검색창에 할 일을 적으면 목록 맨 아래에 'Codex에게 요청: (적은 문장)' 줄이 나온다. 고르면 그 대화가 열리고 입력칸에 문장이 들어가 있다. 보내기는 직접 눌러야 하고, 쓰던 글은 지워지지 않는다. Ctrl/⌘+Enter는 곧바로 그 줄을 실행한다.
- 검색창 아래에 '전체 / Canvas / 저장한 Board' 범위가 생겼고, 좁힌 범위에서 못 찾으면 [범위를 전체로]가 보인다. 방향키로 고른 줄은 색으로 표시된다.
- Codex 로그인이 안 된 채 Desk에 처음 들어가면 맨 위 줄 바로 아래에 'Codex 연결 필요 · 로그인' 한 줄이 나온다(닫으면 다시 나오지 않음).

### 왼쪽 줄

- 눌러도 반응 없던 예시 항목(개발·회의·조사·작성)이 사라지고 내가 저장한 Board 이름이 나온다. 누르면 그 Board가 열리고, 지금 작업 중인 Board는 눌린 모양, 열려 있는 Board는 작은 점으로 표시된다.
- 맨 위 Desk를 누르면 Board 목록이 열리고 다시 누르면 닫힌다. 맨 아래 +는 새 Board를 만든다.
- 저장한 Board가 하나도 없으면 Board 목록에 '저장한 Board가 없습니다'와 [새 Board]·[가져오기]가 보인다.
- 아무것도 없는 책상에는 '위에서 검색, 왼쪽에서 Board, 아래 Dock에서 채팅과 창 열기' 세 가지 시작 단서가 옅게 보이고, 첫 창이나 도형을 놓으면 사라진다.

### Dock

- 버튼이 19개에서 8개로 줄었다: 대화 · 메모 · Browser · 터미널 | 선택 · 이동 · 새 카드(+) | 선택한 창 닫기.
- 새 카드(+)를 누르면 Dock 위에 작은 메뉴가 뜬다: 파일 · 개발 (IDE) · 온톨로지 · 설정, 그 아래 작성 도구 한 줄(펜·사각형·원·선·화살표·글자·강조), 맨 아래 '표식·메모 숨기기'.
- 작성 도구를 고르면 '선택' 옆에 그 도구가 눌린 모습으로 나타나고, '선택'으로 돌아가면 사라진다.
- '표식·메모 숨기기'를 누르면 화면의 도형·표식·메모가 한 번에 사라지고(창 위치와 보는 위치는 그대로) 같은 자리의 '표식·메모 보이기'로 되돌린다.
- 오른쪽 끝 버튼이 휴지통에서 '선택한 창 닫기'로 바뀌었다. 고른 것이 없으면 흐리게 보인다.
- + 버튼의 빈 패널과 '2단계에서 연결됩니다' 같은 개발용 문구가 없어졌다.
- 창을 고른 채 메모를 누르면 메모가 그 창을 가리지 않고 옆 빈자리에 열려 그 창에 이어진다.

### 창 틀 (모든 창 공통)

- 창 왼쪽 위의 빨강·노랑·초록 점이 평소에는 옅은 회색이고, 창 윗줄에 마우스를 올리거나 키보드로 점에 갔을 때만 색이 살아난다. 눌러도 반응 없던 점은 보이지 않는다.
- 노란 점을 누르면 창이 윗줄만 남게 접히고, 다시 누르거나 윗줄을 더블클릭하면 펼쳐진다. 접어 둔 창은 Desk를 다시 열어도 접힌 채로 돌아온다. 채팅 창도 같은 방식으로 접힌다(실화면 검증 뒤 고침. 채팅 창이 Desk를 다시 열 때 접힌 채 돌아오는지는 확인하지 않았다).
- 창을 크게 띄워도(초록 점) 맨 위 줄과 Dock이 그대로 남고, 맨 위에 '○○ · 크게 보는 중'이 뜬다. 누르면 원래 크기로 돌아온다. Browser 창도 같다.
- 화면 전체를 쓰는 집중 보기는 따로 켠다: 맨 위의 [집중 보기], Option을 누른 채 초록 점, 또는 Browser 창 메뉴. 켜져 있는 동안 화면 아래 가운데에 '집중 보기 종료'가 항상 보인다.
- 크게 띄운 채 화면 오른쪽 끝에 마우스를 잠깐 대면 채팅이 창 위로 겹쳐 나온다. [고정]을 누르면 옆에 붙고 큰 창이 그만큼 좁아진다.
- Esc를 누르면 맨 위에 떠 있는 것 하나만 닫힌다: 작은 메뉴 → 확인창 → 검색 결과·Board 목록·기록 패널·미니맵 → 크게 띄운 창 위의 Chat → 크게 띄운 창이 원래 크기로.
- 창을 고르면 뜨던 새파란 테두리가 차분한 녹회색 테두리와 옅은 링으로 바뀌었다.
- 어떤 버튼이든 누르는 순간 살짝 진해지고, Tab으로 옮길 때 어디서나 같은 포커스 테두리가 보인다. Dock·맨 위 줄·보기 줄에서는 좌우 화살표와 Home/End로 버튼 사이를 옮긴다.
- 채팅 창과 터미널 창도 다른 창과 같은 윗줄(창 점 · 잡는 점 · 아이콘 · 이름 · 오른쪽 Board 이름)을 쓴다. 설정 창은 가장자리를 끌어 크기를 바꿀 수 있고 이름이 '설정'으로 나온다.

### Chat

- 입력칸에서 Enter를 누르면 바로 보내진다. 줄바꿈은 Shift+Enter다. 한글을 치다가 마지막 글자를 확정하는 Enter로는 보내지지 않는다.
- 입력칸이 얇은 한 줄로 시작해 글이 길어지면 늘어난다. 글자는 말풍선과 같은 크기다.
- Board Thread 입력칸에 @를 치면 그 방의 Agent 이름과 '나'가 목록으로 뜨고, 고르면 '@이름 '이 들어간다.
- Board 대화방의 '초대'를 누르면 내가 만든 Agent와 기본 Codex가 얼굴·이름으로 나오고, 고른 Agent가 그 얼굴로 들어온다. '멤버 3' 같은 이름은 더 생기지 않는다. 초대만으로는 Agent가 일을 시작하지 않는다.
- 참여자 줄에서 각 참여자가 얼굴로 보이고, 그 방에서 Agent가 일하는 중이면 점이 켜진다(승인·답변 대기는 주황, 막힘은 빨강, 완료는 초록).
- 앱을 막 켰을 때 글자로 남던 Agent 얼굴이 몇 초 뒤 저절로 사진으로 바뀐다.
- 대화에 날짜 줄이 생겼고, 위로 올려 읽는 중 새 답변이 오면 '새 메시지' 버튼이 뜬다. 대화 제목 옆과 목록에 'Agent DM' 또는 'Board Thread' 표시가 붙는다. 'Codex 대화'는 'Agent DM'으로 바뀌었다.
- 보내기가 거절된 내 메시지 아래에 '다시 보내기'가 생겼다. 누르면 같은 내용이 입력칸에 다시 들어간다(자동으로 보내지 않음).
- 아무 일도 없을 때는 입력칸 위 회색 상태 줄이 사라지고, 각 답변의 시간 옆 '…'로 그 답변의 실행 내역을 연다.
- Agent가 허락이나 답을 기다리면 대화 끝 버블에 무엇을 묻는지 한 줄로 보이고 [확인하기]/[답하기]로 바로 간다. 내가 답해야 하는 대기는 '내 확인 N건'으로 강조된다.
- 연결이 끊기면 빨간 상자가 쌓이지 않고 한 줄만 나온다: "연결이 끊겼습니다 · 03:12 확인 [다시 시도] 자세히".
- 채팅에서 자료나 메모를 눌러 다른 곳을 보는 동안 '채팅으로 돌아가기'가 사라지지 않고 떠 있으며, 누르면 떠나기 전 화면과 대화 위치로 돌아온다.
- Agent가 Browser 창에서 일하는 동안 '작업 중' 말풍선 아래와 활동 기록에 [현재 작업 화면]이 생긴다. 활동 기록 위쪽에는 [따라보기](기본 꺼짐)가 있다.
- 추천 자료 줄에 마우스를 올리면 책상 위 해당 창에 점선 테두리가 생긴다.
- Canvas에 띄운 채팅 창은 제목이 열어 둔 대화 이름으로 보이고, 오른쪽에 속한 Board 이름(없으면 '소속 없음')이 있으며, 네 변과 모서리를 끌어 크기를 바꿀 수 있다. '우측' 글자 버튼은 '오른쪽 패널로 옮기기' 아이콘이 됐다.

### Board

- Board 목록에서 삭제를 누르면 무엇이 빠지는지 먼저 묻고 휴지통으로 옮긴다. 목록 아래 '휴지통 N'에서 [복구]와 [완전히 삭제](한 번 더 확인)를 한다.
- Board 이름은 그 줄에서 바로 고친다(F2로 시작, Enter로 확정, Esc로 취소).
- 저장하지 않은 Board를 닫으면 [취소] [저장하지 않고 닫기] [저장 후 닫기]가 보이고, 저장 후 닫기가 기본이다. 같이 닫히는 화면 수와 터미널 수가 창 안에 적혀 있다.
- Board의 [⋯] 메뉴에 '다른 이름으로 저장…'이 생겼다. 지금 구성이 새 Board로 저장되고 열려 있는 Board는 그대로다.
- Board를 저장하면 화면 몇 개가 저장됐는지 한 줄로 알려 준다.
- Board 목록 맨 위의 [저장]·[새 Board]가 테두리와 바탕이 있는 버튼 모양으로 보인다(글자로만 보이던 것을 실화면 검증 뒤 고침).
- 안 쓰는 Board는 줄의 폴더 버튼으로 보관함에 넣고, Board 목록의 '보관함'에서 다시 꺼낸다.
- Board 영역을 둘러싸던 옅은 네모 선과 바탕이 사라지고 이름표만 보인다. 지금 쓰는 Board만 테두리가 남는다.

### Browser · File · Terminal · 설정 · 메모 · 브리핑

- **Browser**: 제목 옆 상태가 한국어로 보인다(불러오는 중 / 보안 연결 / 보안되지 않음 / 이 PC / 사이트). 주소 칸이 얇은 선의 둥근 네모 칸이 됐다. ⌘L(Ctrl+L)은 그 창의 주소 칸으로, ⌘T(Ctrl+T)는 새 Browser 창을 연다. 버튼 줄은 Tab 한 번으로 들어가 화살표로 옮긴다. 창 메뉴의 '최대화 / 창 복귀'는 '크게 보기 / 원래 크기로'가 됐고 '집중 보기'가 생겼다.
- **File**: 처음 열면 가운데에 안내 한 줄과 '폴더 연결' 버튼(그 아래 작은 '보드 프로젝트 연결')만 보인다. 검색 칸과 '파일/변경' 탭은 폴더를 연결한 뒤, 저장·비교 버튼은 파일을 고른 뒤에만 나타난다.
- **Terminal**: 창 이름이 '터미널'이고 이름 옆에 상태(연결 중 / 셸 이름 / 연결 끊김 / 종료됨 / 세션 없음)가 보인다. 명령이 돌고 있는 터미널을 닫으려 하면 '터미널 세션도 함께 종료됩니다. 닫을까요?'라고 먼저 묻는다. 푸르스름한 남색 대신 따뜻한 짙은 회색 한 가지로 보인다.
- **설정**: 탭이 네 개가 됐다(계정, Agent 관리, 화면·입력, 데이터와 초기화). 화면·입력에서 화면 모드를 '시스템 따라가기 / 밝게 / 어둡게' 중에 고르면 바로 바뀌고 다음에 켜도 그대로다. 데이터와 초기화는 무엇이 어디에 보관되는지 보여 주고, 누를 수 있는 것은 '화면 설정 초기화' 하나다. Agent 만들기에는 '예시로 채우기'가 생겼다.
- **메모**: 메모에서 그 메모가 붙은 창까지 선이 보이고, 창이나 메모를 옮겨도 따라온다. 붙어 있던 창이 닫힌 메모에는 원래 어떤 창이었는지와 [다시 연결] [삭제]가 보인다. Agent에게 물은 뒤에는 '답 기다리는 중' 옆에 얼마나 지났는지와 [Chat에서 보기]가 붙는다.
- **브리핑**: [다음]을 누르면 지금 설명하는 창에 세이지색 테두리가 생기고 나머지 창은 살짝 흐려진다. 읽는 동안 Dock과 왼쪽 줄이 조용히 물러난다. 읽다가 닫은 브리핑을 다시 열면 'N단계부터 이어보기 / 처음부터'가 보인다. 남긴 의견은 카드로 보이고 '해결됨으로 표시'·'다시 열기'를 할 수 있다.

### 보기 줄 · 화면 이동

- 창을 차례로 열면 세로 한 줄로 쌓이지 않고 먼저 연 창 둘레(옆·위아래)에 모여 놓인다(실화면 검증 뒤 고침). 창 여섯 개를 연 뒤 [전체 보기]가 20%가 아니라 42%로 맞춰진다.
- 화면 밖으로 나간 창이 있으면 그 방향의 가장자리에 작은 점이 보이고, 누르면 그 창으로 이동한다.
- 보기 줄에 '돌아가기'(이동하기 전에 보던 자리로), '맞춤'(끄면 격자와 안내선에 붙지 않음)이 생겼고, 배율 숫자를 눌러 직접 입력할 수 있다. 확대·축소는 한 번에 1.25배씩이다.
- 창 머리 우클릭 → '이동…'에서 방향키로 창을 옮긴다(16px, Shift와 함께 128px). Shift를 누른 채 창 머리를 누르면 선택에 더하거나 뺀다.

### 색 · 그림자 · 글자

- 채팅방 목록의 동그란 머리글자가 진한 파랑·자주 대신 옅은 세이지·나무·크림 바탕에 진한 글자로 보인다.
- 메뉴·검색 결과·확인창·패널의 그림자가 한 가지 규칙으로 통일됐다.
- 검색 결과의 종류 표시와 미니맵의 도형 표시가 파랑·보라·밝은 노랑 대신 승인된 색으로 바뀌었다. Ontology 지도의 물리 층은 옛 파랑 대신 세이지다.
- 배지와 작은 라벨의 깨알 글자(8~9px)가 10~11px로 커졌다.
- 창 이름과 Agent 이름의 영어가 한국어가 됐다(설정, 온톨로지, 터미널, 도구, 탐색, 구현, 검증, 시스템). 닫기 표시는 글자 × 대신 같은 선 아이콘이다.
- 밝은 테마의 창·왼쪽 줄 그림자에는 승인 시안과 같은 옅은 청회색 기가 남아 있다(결정 필요 — 아래).

### 첫 화면

- **알림 자리(오른쪽 위)는 옮기지 않았다.** 어느 자리든 떠 있는 창과 겹칠 수 있어 저절로 사라지게 하는 쪽으로만 풀었다. 알림 본문은 원래 클릭을 통과시켜 아래 창 조작을 막지 않는다. 오류 알림은 여전히 닫을 때까지 같은 자리에 남는다.
- **Chat의 연결 문제 안내는 바꾸지 않았다.** 수정 작업자가 코드를 읽은 바로는 Chat의 영어 원문은 이미 '자세히' 안에만 있다. 2차 검증은 Chat에도 원문이 그대로 나왔다고 적었으므로 둘이 어긋난다 — 화면으로 다시 봐야 한다.

## 실화면 확인 체크리스트

작업자들이 "실화면에서 볼 것"으로 넘긴 항목을 표면별로 모았다. 밝은 화면과 다크를 둘 다 본다. 2026-11-14 실화면 검증이 본 것은 위 '실화면 검증 결과'에 있고, 이 목록의 대부분은 아직 보지 않았다(본 항목을 여기서 지우지 않았다).

- **맨 위 줄**
  - 창 폭 1200px 이상/미만에서 검색창 위치, 다크에서 계정 원과 자원 고리.
  - 자원 고리를 눌러 작은 창을 연 채 10초쯤 지켜보며 깜박임이 없는지. 네트워크 속도가 B/s ↔ KiB/s ↔ MiB/s로 넘어갈 때 숫자 오른쪽 끝과 단위 왼쪽 끝이 제자리인지, 'MiB/s'가 칸을 넘치지 않는지.
  - 창을 하나 연 뒤 이름 옆 '이 PC에 기록됨 HH:MM'. Browser를 크게 띄웠을 때 툴바로 옮겨 간 고리 4개.
  - 요청 줄 실행 뒤 Chat 입력칸에 초안이 보이고 커서가 들어가는지(Chat이 닫힌 상태, Canvas 채팅 창 상태 각각). 방향키로 고른 줄의 강조, 범위 버튼의 다크 가독성, 한글 조합 중 Enter.
- **왼쪽 줄**
  - Desk를 눌렀을 때 Board 목록이 줄 오른쪽에 뜨고 다시 누르면 닫히는지. 지금 Board 행의 바탕색. Board가 많을 때 줄 안 스크롤.
  - 빈 책상 단서 세 줄의 위치와 첫 창을 놓았을 때 사라지는지.
  - Board 목록 머리줄의 [저장]·[새 Board]는 실화면에서 테두리 없이 글자로만 보여 버튼 모양으로 고쳤다(2차 확인). [가져오기]는 검증 상태에서 나오지 않아 못 봤다.
- **Dock**
  - 1100×720에서 Dock 폭(계산상 약 344px), 메뉴가 Dock 위 8px에 뜨는지, 다크에서 메뉴와 흐린 닫기 버튼, Esc가 메뉴만 닫는지.
- **창 틀**
  - Browser 창을 접었다 펼 때 페이지가 그대로 돌아오는지(특히 Agent가 조작 중일 때).
  - 활성 테두리·링이 시안과 비슷한지, 윗줄에 마우스를 올렸을 때 점 색 전환과 Browser 창의 점 크기, 접힌 창의 모서리·그림자.
  - 설정 창 가장자리 끌기와 격자 맞춤.
  - Esc 순서: Chat 대화방 메뉴 → 설정 계정 메뉴(Esc/바깥 클릭/↓) → 창을 크게 띄우고 Esc → 한글 조합 중 Esc → 터미널 안 Esc.
  - 크게 보기: '○○ · 크게 보는 중'을 눌렀을 때 창 끌기가 아니라 클릭으로 먹는지, 오른쪽 끝에 대면 채팅이 겹쳐 나오는지, [고정] 때 큰 창이 다시 맞춰지는지, Browser를 크게 띄웠을 때 맨 위 줄과 Dock이 남는지, '집중 보기 종료' 위치.
  - 버튼 눌림 색이 실제로 보이는 정도, 아이콘 크기와 가운데 정렬, 화살표 키 이동이 실제로 되는지.
- **Chat**
  - 빈 입력칸 한 줄 높이와 안내 글자의 세로 가운데 정렬, 여러 줄에서 140px까지 늘고 스크롤되는지.
  - Board Thread에서 @ 목록의 위치(입력칸 바로 위 왼쪽)와 다크 대비, 짧은 채팅 창에서 목록이 잘리지 않는지. 한글 마지막 글자에서 Enter 한 번에 한 번만 보내지는지.
  - Board 대화방: 초대 → 목록 → Agent 선택 → 칩에 얼굴·이름, Esc/바깥 클릭/다시 누르기로 닫힘, 칩을 누르면 멤버 메뉴, Agent가 답하는 동안 칩의 점, 앱을 막 켠 직후 얼굴이 몇 초 뒤 사진으로 바뀌는지.
  - 채팅 창 틀: 창 점 위치·간격, 좁은 폭(320~400px)에서 이름 말줄임과 '소속 없음' 자리, 가장자리 끌기와 스크롤바 겹침, Board 영역에 놓았을 때 제안 위치.
  - '채팅으로 돌아가기'가 계속 남고 원래 화면·스크롤로 돌아오는지, [닫기]와 Esc. Agent가 Browser를 조작하는 동안 [현재 작업 화면]. 추천 자료 줄의 점선 테두리. [따라보기]가 손으로 화면을 옮기면 1초 안에 꺼지는지. 활동 기록 420px 머리줄에 버튼 셋이 한 줄에 들어가는지.
  - 거절된 메시지에서 '다시 보내기' 뒤 보내기 버튼이 켜지는지. 날짜 줄·'새 메시지' 버튼의 다크 가독성. 연결 끊김 한 줄과 대기 버블.
- **Board**
  - Board 목록(휴지통·보관함·이름 변경), 닫기 확인창, '다른 이름으로 저장' 창. Board 줄의 버튼이 4개가 되어 좁은 목록에서 이름이 얼마나 잘리는지.
- **Browser · File · Terminal · 설정**
  - Browser: ⌘L/⌘T가 웹 내용에 포커스가 있을 때도 잡히는지, 주소 칸 모양, Tab 한 번 진입 뒤 화살표 이동.
  - File: 빈 창의 안내와 버튼이 세로 가운데인지, 폴더 연결 뒤 툴바가 기본 크기(696px)에서 한 줄인지, 탭 밑줄, 다크에서 '폴더 연결' 글자 대비.
  - Terminal: 머리줄과 본문 사이에 띠가 없는지, 초록 점으로 키운 뒤 글자 영역이 다시 맞춰지는지, 닫기 확인 띠의 초점 이동.
  - 설정: 시스템 밝음 + '어둡게', 시스템 어두움 + '밝게'에서 검색 결과·Board 메뉴·확인창·설정 창 글자가 읽히는지, 스크롤바·입력칸 색.

  - 메모: 접힌 메모 윗줄에 '메모 #N'이 다 보이는지, 선이 창 아래 층에서 보이고 확대·이동을 따라오는지, [다시 연결] 중 Browser 창의 웹 내용을 눌렀을 때 대상으로 잡히고 그 클릭이 페이지에 전달되지 않는지, 채팅 창이 열린 상태에서 Dock 메모가 채팅을 가리지 않는지.

그 밖의 작은 추론(바꾸기 쉬운 것):

- Dock: 숨김 표시는 + 버튼의 작은 점과 '숨김 N개'. 닫기 버튼은 흐리게 보여도 키보드로 닿는다.
- 검색: '저장한 Board' 범위는 저장된 Board와 그 안의 Browser 주소만 포함. 범위 선택은 앱을 켜 둔 동안만 유지. Alt/⌥ 1·2·3 단축키는 새로 정한 것.
- Chat: @ 목록은 앞에서 일치 다음에 포함 일치. '나' 줄의 보조 글자는 '대표님'. 초대 목록은 지금 쓸 수 있는 저장된 Agent와 기본 Codex만(같은 이름이 둘이면 먼저 것만). '접수 미확인' 메시지에는 '다시 보내기'를 주지 않음. 연결 줄이 떠 있는 동안 '로컬 기록을 확인하지 못했습니다'는 '자세히' 안으로. 승인·답변 자체는 활동 기록에 둠. [따라보기]는 기본 꺼짐. 추천 자료 강조는 2px 점선.
- 채팅 창: 윗줄 높이는 다른 창과 같은 32px(시안의 41/34px 아님). 최소 크기 320×420.
- 창 틀: 접힌 창은 저장 크기를 그대로 둠. 설정 창은 노란 점 숨김. 크게 보기의 [고정]은 그 한 번 동안만 유지. 창 이름은 18자에서 줄임.
- 메모: 옆에 둔 메모를 빈 곳으로 옮겨도 연결 유지. '원래 창' 이름은 창 종류 수준만 저장(페이지 제목은 저장하지 않음).
- 색: 방 목록 얼굴은 방마다 정해지는 6톤 중 하나(그 방 Agent의 프로필 색이 아님). Board 이름표에 포인터를 올리면 범위가 옅은 선으로 보임(승인 시안에 없는 동작). Ontology는 두 테마 모두 밝게.
- 브리핑: 흐림은 덮개가 아니라 대상이 아닌 창의 불투명도 0.5. 읽던 단계는 앱을 켜 둔 동안만 기억.
- Board: '다른 이름으로 저장'의 새 이름은 목록의 Board와 겹치면 거절. 열려 있는 Board는 보관해도 목록에 남고 '보관됨'으로 표시.
- Browser: 주소 글자는 12px 유지. 크게 보는 중의 ⌘T는 가로채지 않음.
- 보기 줄: 가장자리 점은 한쪽 3개 초과 시 +N. '돌아가기'는 직전 구도 1개만 기억. 맞춤은 기본 켬.
- 자원 표시: 유효 숫자 3자리, 디스크·네트워크는 두 줄 고정.
- 설정: '예시로 채우기'는 빈칸만 채우고 저장하지 않음.

## 하지 않은 것 · 남은 것

### 맡았지만 남긴 것

- **맨 위 줄**: 빈 책상에서도 미니맵 아이콘은 남는다. '기록 중' 상태·미기록 변경 개수·진단 정보는 없다. 검색의 [지우기], 6행 제한과 [더 보기], Library 범위는 없다. 고정된 Agent 대화도 없고 Chat도 열려 있지 않으면 요청 줄이 나오지 않는다.
- **Dock**: 표식·메모 숨김은 화면 전체 단위뿐이다. 숨긴 동안 Dock 밖 경로(창 메뉴, Agent)로 만든 메모·표식은 다시 보이기를 누를 때까지 안 보인다. 미니맵에는 숨긴 표식이 그대로 나올 수 있다. 지운 것을 되살리는 목록은 없다.
- **창 틀**: 설정·터미널 창은 접히지 않는다(채팅 창은 실화면 검증 뒤 접히게 고쳤다). Browser 창의 점 간격이 다른 창과 다르다. 창 윗줄의 상태 표시 통로와 내용 불러오기 실패 화면은 만들지 않았다. Browser 창 메뉴·Agent 기록 팝오버·자원 상세·내보내기/가져오기 창·답변 브리핑·Chat 프로젝트 연결 패널은 포커스가 밖에 있을 때 Esc가 건너뛴다. 크게 보기의 채팅 엿보기·고정과 Esc 순서는 두 작업이 따로 만들어 서로 맞춰졌는지 확인되지 않았다. Agent 칩·알림으로 여는 엿보기, 집중 보기의 Esc 종료는 없다.
- **Chat**: 채팅 창 윗줄 아래의 대화 줄(뒤로·대화 이름·엔진·사용량·메뉴·멤버)이 그대로라 대화 이름이 두 번 보인다. 보내기 버튼을 상자 밖으로 빼는 배치는 하지 않았다. 초대한 Agent에게 실제로 일이 가는 것(여러 Agent 실행)은 범위 밖이다. 떠 있는 Chat 패널에서는 멤버 줄·초대가 나오지 않는다. 연결이 끊긴 빈 대화의 가운데 '로그인 필요' 카드는 그대로 같이 보인다. 터미널 종료를 기다릴 때 '터미널 열기'는 없다. 활동 기록의 줄마다 대상 창 버튼은 없다.
- **File**: File 창 윗줄의 Agent 얼굴·이름은 없다(Agent가 다루는 파일과 열린 File 창을 잇는 정보가 화면에 없음).
