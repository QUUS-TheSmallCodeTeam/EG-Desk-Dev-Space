## Variant: Miro Spatial Canvas

> Historical sketch. It uses the retired three-stratum/side-lens grammar and
> must not be treated as the composite-lens v2 specification.

### Design stance
Bright canvas direction. Best for direct-manipulation and object-on-surface readability.

### Key choices
- Layout: selected stack with side lens and three time panes.
- Typography: compact Inter/system scale with mono metadata.
- Color: strict virtual/information/physical accents.
- Interaction: clicking a node updates the lens selected object.

### Trade-offs
- Strong at: making one visual grammar obvious.
- Weak at: this is a disposable sketch; production geometry and verifier still need to be ported.

### Best for
Choosing an ontology visual direction before Codex touches production CSS/JS.
