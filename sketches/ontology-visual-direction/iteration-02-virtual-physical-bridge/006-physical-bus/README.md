## Variant: Physical Bus

> Historical sketch. The `virtual → information → physical` chain below is
> retired; information is not a third runtime stratum in composite-lens v2.

### Design stance
physical substrate as a visible bus that selected virtual objects plug into.

### What changed from iteration 01
- The virtual-to-physical bridge is now the primary visual object.
- Same-layer relations are muted.
- Physical substrate is a labeled endpoint, not a faint footer.
- The selected object exposes a continuous `virtual → information → physical` chain.

### Trade-offs
- Stronger causal legibility.
- More visually opinionated; may need restraint before production.
