## Variant: Runtime Cutaway Rail

> Historical sketch. The global runtime-rail grammar was not adopted for
> composite-lens v2.

### Design stance
A selected virtual object exposes a runtime cross-section rail. The rail is the primary artifact; side nodes are context.

### Why this exists
Earlier candidates failed because they showed layers without making the virtual-to-physical connection point central.

### Expected improvement
- The chain is visually central and labeled at all three endpoints.
- Physical substrate is an endpoint of the selected object, not a footer.
- Same-layer edges are muted.
- The design is still dark/product-tool enough for EG-Desk.
