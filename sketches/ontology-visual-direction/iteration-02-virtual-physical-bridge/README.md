# Iteration 02: Virtual-Physical Bridge

> Historical exploration only. The current viewer has two runtime strata and
> uses local composite rectangles plus reference edges; it does not use a
> global runtime rail/bus as its primary grammar.

The first three candidates failed because they showed layers but did not foreground the connection point between virtual and physical.

New variants:

1. `004-conduit-spine` — central vertical runtime conduit.
2. `005-cutaway-column` — sliced desk surface / cross-section column.
3. `006-physical-bus` — physical substrate as a bus that semantic objects plug into.

Evaluation priority:

- Can the user immediately see where a virtual object touches runtime/physical substrate?
- Is the bridge more prominent than same-layer graph edges?
- Does physical feel causal, not decorative?
