## Variant: Port and Physical Bus

> Historical sketch. The global port/bus grammar was not adopted for
> composite-lens v2.

### Design stance
The selected virtual node has an explicit output port into a runtime cutaway rail, and the rail terminates in a physical bus fanout to CPU/RAM/Disk.

### Fixes over 007
- Explicit port on selected virtual node.
- Visible main chain from selected node to rail.
- Physical bus connects rail to CPU/RAM/Disk with taps.
- Physical endpoints are less like disconnected bottom cards.
